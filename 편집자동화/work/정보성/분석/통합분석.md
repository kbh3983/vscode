**지식인사이드(교양 에이전트)와 다른 점**
- 지식인사이드는 대담 + 큰 강조 자막 + Question 카드 + 칠판 패널. **궁금한뇌**는 형식이 가장 비슷하지만, 그래픽이 **앱 화면 모티프로 통일**되고 기본 자막이 **말하는 사람 이름이 붙은 말풍선**이다. 효과음 양은 비슷하거나 적다.
- **탐구생활**은 대담이 아니라 1인 설명이라 결이 아예 다르다. 그래픽이 디자인 템플릿보다 **자료(사진·영화·화면 녹화) 위주**이고 효과음이 거의 없다.
- **세바시 인생질문**은 지식인사이드처럼 '전문가 강연'이지만 **진행자 없이 게스트 혼자** 질문에 답한다. 큰 강조 자막·효과음이 적고 다큐처럼 **차분한 타이포·스톡·조명**으로 분위기를 만든다.

### 2-2. 디자인 모티프 — **앱·운영체제 화면**
채널 전체 그래픽이 아이폰·맥 화면 요소로 통일돼 있다.
- 기본 자막 = **메신저 말풍선**(오른쪽 "···" 더보기 단추)
- Q 카드 = 흰 둥근 **앱 아이콘** + 파란 Q
- 용어 카드 = 파란 **앱 아이콘(전구)** + 단어 + 영어 + 반투명 상자 + 오른쪽 "?" 단추 (두 코너 공통)
- 키워드 카드 = 맥 **창**(위 점 3개)
- 엔딩 = **Finder 창**에 "궁금한 뇌" 폴더 + 제작진 목록

- 궁금한뇌형 템플릿: 말풍선 대사(이름···· 칸), 흰 대사 + 색 이름, Q 카드(왼/오른쪽), 용어 카드(아이콘·단어·영어·설명), 큰 강조(흰 / 노랑 단어 + 파란 라벨 / 파란 밑줄 띠), 단계 번호, 이름 카드(액자), 타이틀 카드(글자 차오름), 엔딩(창 크레딧)

**읽는 법과 알게 된 것**
- **목소리 압축(고르게 누르기)**: 궁금한뇌가 가장 세다 — 목소리 크기 폭 5.7~10dB, 크레스트 11~15dB. 탐구생활·세바시는 폭 10~14dB, 크레스트 13~17dB로 덜 누른다(자연스러운 강약). 궁금한뇌는 라디오·팟캐스트처럼 귀에 붙는 소리
- **저음 깎기(로우컷)**: 탐구생활은 120Hz 아래가 0.1~0.5%만 남아 **로우컷을 세게** 건다. 세바시는 r11·r12 0.1%, r13~r15 4~7%(회차마다 다름). 궁금한뇌는 9~22%로 **저음을 살린다**(라디오 목소리처럼 두툼)
- **모노**: 15편 모두 좌우 상관 0.99~1.00
- **음량**: 통합 −16.4 ~ −24.3 LUFS로 제각각이고, 피크를 0dBTP 근처까지 올린 회차가 많다(리미터 마감이 엄격하지 않음) → 음량은 레퍼런스를 따르지 않고 우리 마감 기준을 쓴다
- **LRA(크기 변화)**: 궁금한뇌 3~6, 세바시 5~7, 탐구생활 6~15(현장편이 큼) — 스튜디오 대담일수록 고르다
- **완전 무음(0.3초 넘게)**: 궁금한뇌 r3, 탐구생활 r7·r8, 세바시 r12·r14에서 수십~수백 번 → 이 회차들은 말 사이 숨·잡음을 지워(게이트) **무음**을 만든다. 나머지는 실내 잡음을 남긴다
- **음악 위치**: 궁금한뇌·세바시는 처음·끝에만 길고 본론은 짧은 조각(궁금한뇌 r2·r3은 1~2분마다 짧게) / 탐구생활 현장편(r10)은 본론에도 자주

## 6. 한계·확인할 것
- 효과음 종류는 소리 성격과 화면으로만 추정(듣지 않음)
- 폰트 이름 미확인 — 궁금한뇌 대사·강조는 Pretendard 계열 고딕으로 보이고, 로고·손글씨·명조는 따로. 탐구생활 대사는 둥근 고딕(가는 굵기)
- 0.1초 간격 움직임은 궁금한뇌 r1(Q·용어 카드·강조·말풍선)만 확인. 나머지는 1초·10초 간격
- 실제로 받을 정보성 일이 어느 쪽(대담 / 1인 설명 / 1인 인터뷰)에 가까운지에 따라 기준을 고른다
- 세바시는 0.1초 간격 움직임을 보지 않았다(1초·10초 간격만)
