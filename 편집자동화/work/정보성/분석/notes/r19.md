# r19 — 「크랩(klab)」 (로고상 지식인사이드가 아닌 별도 채널로 보임 — 사용자 확인 필요) 「줄줄이 취소되고 있는 네옴시티, 결국 무산될까」 (7.1분) — **해설 다큐형**
- **출연자 없이 내레이션 + 자료화면**(지식인초대석·클래스와 형식이 완전히 다름). 오른쪽 위 "klab"/"크랩" 로고 항상
- 구조: 0~27초 인트로(자료화면 + 화면 가득 초록 네온 "네옴시티", 뉴스 헤드라인 스티커 2줄 노랑 형광펜) → 27~29초 "크랩" 로고 → 본론(장 제목 = 초록 대괄호 큰 글자 "[ 더 라인 ]" "[ 옥사곤 ]")
- 자막: 기본 = 화면 아래 흰 고딕 박스 없음 ≈36px. **인터뷰 전문가는 왼쪽 아래 원형 얼굴 사진 + 굵은 이름 + 작은 소속 + 흰 반투명 상자 대사**(2:45 "노다솔 연구교수…")
- 그래픽: **초록 배경 일러스트·누끼 콜라주**(왕세자 오려 붙이기 + 말풍선 + 확성기 + 깃발), 가계도 도식(왕관 아이콘), 선 그래프(빨간 점선 기준선 $90), **연표**(노랑 선 + 연도 깃발 2027·2030 + 로고), 지도 + 국기·로고, 기업 로고 + 말풍선
