# r3 — 궁금한뇌 「다들 이정도는 버티고 사는 거 아닌가요」 (26분) — 코너 **WELLNESS RADIO** (r2와 같은 코너)
진행 장동선(파랑 니트) + 게스트 노현재(정신과 전문의). r2와 같은 밝은 서재·붐 마이크 세트, 강아지·고래 인형.
→ **같은 코너는 틀이 같음**: 박스 없는 흰 대사 + 왼쪽 이름, Q 큰 자막, 앱 아이콘 용어 카드, WELLNESS RADiO 로고, Finder 엔딩.

## r2와 같은 점 (코너 틀)
- 콜드 오픈 없이 인사로 바로 시작(0:00 "안녕하세요 뇌과학박사 장동선입니다") → 0:04 로고 작게 → 게스트 소개 → 0:11 2샷에 **에피소드 제목 손글씨 카드**("고기능 우울증", 위쪽 가운데) → 0:15 "안녕하세요!" 파란 글자 → 0:45~0:56 스톡 재연(콜드 오픈 대신 상황 재연 몽타주) → 0:57 **Q 큰 자막**("고기능 우울증이란?")
- 이름 색이 **사람마다 다름**: 장동선 = 하늘색(청록), 게스트 = 연두 — 왼쪽 고정(x≈30~120)
