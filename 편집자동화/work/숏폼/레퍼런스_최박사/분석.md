# 최박사 채널 잘된 숏폼 4개 분석 (2026-10-14)

입력: `input/숏폼_레퍼런스/` (파일명 = 유튜브 제목). 방법: 한국어 트랙 받아쓰기(단어 시간), 프레임 차이로 컷 검출, 2초마다·컷마다 프레임(`r*_sheet.jpg`), 말 없는 구간 소리 크기. 스크립트 `analyze.py`
- 오디오 트랙이 2개씩 — **두 번째는 유튜브 자동 영어 더빙** (분석 제외)

| # | 업로드 제목 (파일명) | 상단 제목 (화면) | 길이 | 컷 | 평균 샷 |
|---|---|---|---|---|---|
| r1 | 골반이 편해지는 기적의 운동법 1가지 #골반교정 | 코어 운동 1도 모르면 / **'이것'만 따라하면 됩니다** | 1:40 | 8 | 11.1초 |
| r2 | 운동할 때, 허리가 아팠던 이유 \| 초이스 굿모닝 엑서사이즈 #건강정보 #운동 | 몸과 뇌가 '이 움직임'을 기억하면 / **더 이상 허리 아프지 않을 겁니다** | 1:12 | 25 | 2.8초 |
| r3 | 허리 통증 잡는 초간단 장요근 운동 👀 | 중년 이후 꼭 해야하는 / **허리 통증 삭제 운동** | 1:06 | 11 | 5.5초 |
| r4 | 🔥누워서 하는 초간단 코어 운동 🔥 #코어운동 | 하루 30초 누워서 / **탄탄 코어 완성 운동** | 1:17 | 12 | 5.9초 |

## 1. 오디오 (대사)
### 첫 문장 (훅) — 모두 2~4초 안에 문제·주장
| # | 첫 문장 | 유형 |
|---|---|---|
| r1 | "이게 장요근이라는 근육인데 굉장히 중요한 코어 근육입니다" + 해부 그림 → 24초 "솔직하게 말씀드릴게요, 이미 굳어 있으신 분들은 (흔한 스트레칭으로) 거의 안 돼요" | 정보(근육 이름·중요성) → **상식 반전** |
| r2 | "이렇게 하시면 전형적으로 허리 아프시게 될 거예요" | **경고형 상식 반전** (틀린 자세를 먼저 보여 줌) |
| r3 | "저는 가급적이면 쉽게 따라할 수 있고 고효율적인 운동을 좋아하거든요" → "보통 무릎 끌어올리는 동작인데 다른 근육들이 많이 개입해요" | **쉬움·효율** → 상식 반전 |
| r4 | "난 코어의 힘을 잘 못 느꼈다 하시는 분들은 이 동작으로 연습해 보세요" | **공감되는 고민** |

### 구성 (4개 공통)
**① 훅(문제·오해) → ② 왜 안 되는지 원리 한두 문장 → ③ 해결 방법(대부분 도구: 터틀볼·웨이트볼·스틱) 단계별 → ④ 자극 확인 순간 → ⑤ 원리 정리 또는 권유로 끝**
- ④ 자극 확인이 꼭 있음: "어? 여기가 장요근이었구나 라는 느낌", "그게 지금 장요근입니다", "이 들어오는 코어 힘 이걸 느끼셔야 돼요", "그렇게 돼야 돼요"
- ⑤ 끝: 원리("안정성이 떨어져서 코어 전체가 개입", "그게 안 되기 때문에 허리가 아픈 거예요") 또는 권유("걸음걸이가 이상하고 허리가 자주 불편하면 … 이 운동을 한번 해보세요"). **말로 하는 구독·댓글 유도는 없음**
- 도구 = 플레오라 제품(터틀볼·웨이트볼)이 **해결의 핵심**으로 자연스럽게 등장: "이때 터틀볼을 활용하시면 훨씬 용이하게", "터틀볼을 활용하게 되면 완전 달라져요" (r1·r3·r4)
- 원리 설명이 앞서 본 템플릿 예시보다 많음 (왜 그런지 2~3문장) — 그래도 한 문장이 짧고 말 사이 쉼이 거의 없음
- 길이 **66~100초** (앞서 본 예시 39~79초보다 김)

## 2. 비디오
### 레이아웃 A — r1·r3·r4 (최박사 트레이너 영상)
- 1080×1920. 위: **상단 제목 2줄**(흰색 / 노랑, 따옴표 강조 '이것') y 190~345 → 청록 선 → **영상 1080×1080 정사각**(y 419~1498, 가로 영상을 인물·동작 중심으로 확대·크롭) → 보라 선 → 아래 검정 여백(y 1500~1920, 끝부분에만 라이브 안내)
- **영상 안 아래쪽에 대사 자막이 계속** (흰 글자·검정 띠, 핵심어 노랑). 같은 자리에 안내 박스가 번갈아 나옴:
  1. 0~8초 **프로필 카드** "최문기 박사 / 《최박사의 운동 혁명》 저자 / 운동생리학 박사 / 운동 지도 15년 이상 / 보디빌딩 우승 경력"
  2. 8~15초 "굳고 틀어진 몸, 4주면 바뀝니다🔥 / 단톡방 신청은 고정댓글 링크를 확인하세요!" (r1은 "▼링크는 고정댓글을 확인해주세요▼ 플레오라 4주 단톡방에 참여하시면…")
  3. 도구가 나오는 동안 "영상 속 '플레오라 운동 기구'가 궁금하시다면? / 네이버에 '플레오라'를 검색해보세요"
  4. 끝부분 영상 아래: "유튜브 화요일 오후 8시🔴 / 최박사의 운동 혁명 라이브 본·방·사·수"
- 시각 장치(많이 씀): **해부 그림**(장요근 구성 정지 그림 r1·r3 앞부분, 근육 강조 애니메이션 r3·r4 끝), **화살표**(청록, 미는·당기는 방향), **빨간 X**(틀린 자세), **노란 점선 원**(자극 부위·도구 강조), **큰 글자 효과**("초간단 장요근 강화 운동" 불꽃, "30초 버티기", "으악~!"), **확대 컷**(도구·발 클로즈업)
- 컷: 시범은 길게(5~28초), 말 사이 쉼만 점프 컷

### 레이아웃 B — r2 ("초이스 굿모닝 엑서사이즈", 다른 출연자·AMT 시리즈)
- 상단 제목 2줄 → 영상이 **아래 끝까지 꽉**(1080×1527) → 화면 가운데 **큰 자막**(노랑·흰색, 굵게)
- 컷이 빠름(평균 2.8초, 대화 주고받기), 확대 삽입 컷, "!" 팝, 불꽃 글자 강조, 안내 "네이버에 'AMT 4주 운동' 검색하세요! AMT 단톡방에서 함께 운동해요🔥"

## 3. 소리
- r1·r3: 말 없는 구간 −50dB 안팎 → **배경음악 없음**
- r2: 말 없는 구간도 −30dB → **배경음악이 깔린 것으로 보임**
- r4: 말 없는 구간 −34dB, 7.8·11.7·21.6초 등에 짧은 큰 소리 → **효과음일 가능성** (확인 필요)

## 5. 상단 제목 공식 (보강)
- 1줄 = 대상·조건(코어 운동 1도 모르면 / 중년 이후 꼭 해야하는 / 하루 30초 누워서 / 몸과 뇌가 '이 움직임'을 기억하면), 2줄(노랑) = 약속·결과(**'이것'만 따라하면 됩니다** / **허리 통증 삭제 운동** / **탄탄 코어 완성 운동** / **더 이상 허리 아프지 않을 겁니다**)
- 장치: 따옴표로 궁금증('이것', '이 움직임'), 숫자(30초, 1도), 대상 지정(중년 이후), 강한 결과어(삭제, 완성, 더 이상 ~않을)
- 업로드 제목은 상단 제목과 다르게: 증상·부위 + 쉬움("초간단", "누워서") + 이모지·해시태그
