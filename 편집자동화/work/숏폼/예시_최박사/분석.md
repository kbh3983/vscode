## 1. 선별 (어느 구간을 고르나)
- **구성 공식: 훅(문제·주장) → 방법 핵심(자세 → 동작) → 효과 확인 / 참여 유도**

  - 둔근2: "왕초보 둔근 운동 2탄" → 동작 설명 → "끝까지 들고 할 수 있었다 댓글로 번호 남겨주세요" (참여 유도로 끝)
  - 스틱: "스쿼트할 때 허리 무너지는 분들 → 이 영상 꼭 제대로 봐주세요" (공감 고민) → 불안정한 곳에선 보상 작용이 안 됨(원리 한 줄) → 스틱 잡는 법 → "땅에서 다시 해보면 기울었던 게 좋아졌을 거예요" → "기능성 운동 먼저, 중량 운동 다음" (꿀팁으로 끝)
