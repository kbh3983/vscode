# 오디오 리포트 — 옆구리살_가편 (2026-10-06)

- 프로젝트: `261006_최박사_운동법_AI.prproj`
- 원본 시퀀스: `옆구리살_가편` (손대지 않음) → 작업본: **`옆구리살_가편_오디오2`** (저장 완료)
- 방법: **게인으로 평균을 맞추고 → 선택적 제한으로 -6 dB 상한** (사용자 지정)
- 조절 대상: **오디오 2 트랙만** (C0027, C0028). 오디오 1(B캠)은 그대로
- `옆구리살_가편_오디오`(키프레임 방식)는 쓰지 않기로 한 시퀀스입니다. 지워도 됩니다

## Premiere에 적용한 것 (오디오 2 클립 2개, 같은 값)
| 이펙트 | 값 |
|---|---|
| 선택적 제한 — 입력 증폭 | **+8.15 dB** (게인 역할) |
| 선택적 제한 — 최대 진폭 | **-6 dB** |

- +8.15 dB는 말 구간 최고 음량의 중앙값을 -13.0 dB에서 -5 dB로 올리는 값입니다
- 클립 '오디오 게인'은 스크립트로 바꿀 수 없어서(읽기 전용) 리미터의 입력 증폭에 넣었습니다. 리미터 바로 앞에서 키우는 것이라 '게인 → 리미터'와 소리가 같습니다
  - 오디오 게인으로 하고 싶으시면 두 클립에 오디오 게인 +8.15 dB를 넣고 입력 증폭을 0 dB로 바꾸면 됩니다

- 범위 아래(-7 dB 미만) 9개 구간: 원래 아주 작은 말이거나 숨소리·잡음입니다
