# 오디오 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값.

## 목표 음량
| 종류 | 범위 | 겨냥값 | 상태 |
|---|---|---|---|
| 말소리 | -4 ~ -6 dB | -5 dB | 확정 (사용자 지정, 2026-10-05) |
| 배경음악 | -18 ~ -21 dB | -19.5 dB | 확정 (사용자 지정) |
| 효과음 | -10 ~ -12 dB | -11 dB | 확정 (사용자 지정) |

## 측정
| 항목 | 값 | 상태 |
|---|---|---|
| 측정 기준 | 최고 음량(피크, dBFS) — Premiere 오디오 미터 값 | 초안 (사용자 확인 필요) |
| 말소리 측정 단위 | 문장(말 구간)마다 | 초안 |
| 말소리 피크 계산 | 구간 안 상위 1% 큰 소리 제외 후 최고값 (순간적인 튐 하나에 끌려가지 않게) | 초안 |
| 배경음악·효과음 | 클립 사용 구간 전체의 최고값 | 초안 |

## 조절
| 항목 | 값 | 상태 |
|---|---|---|
| 말소리 ① 게인 | 말 구간 최고값 중앙값을 -5 dB로 맞추는 값 (선택적 제한의 입력 증폭에 넣음) | 확정 (사용자 지정, 2026-10-06) |
| 말소리 ② 상한 | 선택적 제한 최대 진폭 -6 dB | 확정 (사용자 지정, 2026-10-06) |
| 구간별 키프레임 | 쓰지 않음 | 확정 (사용자: 비효율) |
| 범위 밖 허용 | 없음 — 조절 후 다시 측정해 벗어나면 리포트 | 확정 |

## 모노 사운드 (두 출연자 핀마이크가 좌·우에 따로 녹음된 경우)
| 항목 | 값 | 상태 |
|---|---|---|
| 섞는 방법 | 채널 혼합기 L→L·R→L·L→R·R→R 모두 +100% (양쪽 = L+R). 두 사람 차이가 크면 교차 값으로 비율 조정 | 확정 (사용자 승인, 2026-10-09) |
| 음량 | 섞은 뒤 새 선택적 제한: 말 구간 피크 중앙값 −5 dB가 되는 입력 증폭, 최대 진폭 −6 dB | 확정 (사용자 승인, 2026-10-09) |
| 첫 작업 범위 | 처음 **10초**만 별도 시퀀스로 먼저 | 확정 (사용자 지정, 2026-10-09) |
| 작업 트랙 | A1만. 다른 음성 트랙은 **음소거만, 지우지 않음** (싱크용). **효과음 트랙은 음소거하지 않음** | 확정 (사용자 지정, 2026-10-09) |
| 원본 시퀀스 | 아무것도 건드리지 않음 | 확정 (사용자 지정) |

## 콧바람 노이즈 (두 출연자 핀마이크가 L·R에 따로 녹음된 경우)
| 항목 | 값 | 상태 |
|---|---|---|
| 무엇 | 운동 중 자연스러운 숨소리가 아니라 **코로 세게 내쉰 바람이 핀마이크에 닿는 소리** → 그 구간만 그 사람 채널을 끄고 반대 채널로 채움 (프리미어 "좌측과 우측 채우기" = R 끔 / "우측과 좌측 채우기" = L 끔) | 확정 (사용자, 2026-10-14: "운동 시 자연스러운 숨소리가 아닌, 콧바람 같은 노이즈가 들어가서 그 출연자의 오디오를 끈 거야" → "9번은 승인할게") |
| 찾는 규칙 | 한쪽 마이크에만 6dB 이상 크게(−50dBFS 넘음, 60ms 이상) + **저음(300Hz 아래) 비율 0.8 이상 + 중심 주파수 250Hz 아래** (`scripts/audio/nose_noise.py`). 숨소리·말소리는 저음 비율 약 0.13·중심 약 620Hz | 초안 (하체루틴 시험: 사용자가 끈 14클립 중 11개 잡힘, 그대로 둔 클립 11곳도 잡힘) |
| 진행 방식 | **처음에는 후보만** 시점·채널·크기 목록으로 주고, **사용자가 승인한 것만** 채널 채우기. 후보마다 결정(승인/아님)을 `nose_choices.md`에 쌓음 | 확정 (사용자, 2026-10-14: "초반에는 후보를 주면 내가 승인한 뒤, 데이터가 어느정도 쌓이면 그 때는 자동화 하는 방향으로 가자.") |
| 자동화로 넘어가는 때 | 결정이 충분히 쌓이면(초안: 영상 3편 이상, 규칙과 사용자 결정이 90% 이상 일치) 자동화를 **사용자에게 제안** — 자동으로 바꾸지 않음 | 초안 |

## 덕킹 (선택)
| 항목 | 값 | 상태 |
|---|---|---|
| 말소리 구간 배경음악 | -21 dB (범위 아래쪽) | 초안 |
| 말 없는 구간 배경음악 | -18 dB (범위 위쪽) | 초안 |
| 전환 시간 | 0.3초 | 초안 |
