# 오디오 — 승인된 좋은 결과

사용자가 **명시적으로 승인한 결과만** 기록한다. 다음 작업에서 이 방법을 따른다.

형식:
```
## [단계 A1~A7] 제목 (날짜, 프로젝트명)
- 상황 (시퀀스, 클립 구성):
- 한 방법 / 사용한 값:
- 사용자 피드백 (원문):
- 다음에 적용할 점:
```

## [A3~A6] 말소리: 게인으로 평균 + 선택적 제한 -6 dB (2026-10-06, 261006_최박사_운동법_AI / 옆구리살_가편)
- 상황: 22분 인터뷰 시퀀스, A1 B캠(작음, 그대로 둠) + A2 C캠(C0027·C0028, '좌측과 우측 채우기'로 왼쪽 채널만 들림). 자막 없음, 배경음악·효과음 없음. 사용자 지시로 A2 트랙만 조절
- 한 방법 / 사용한 값:
  1. 시퀀스 복제 (`옆구리살_가편_오디오2`)
  2. `levels.py`로 측정: 말 구간(에너지로 자동 검출, 0.3초 이상 368개)의 최고값(상위 1% 제외) 중앙값 -13.0 dB. 클립의 채널 이펙트(`"fill": "L"`)를 반영해 실제 들리는 소리 기준으로 측정
  3. 게인 = 중앙값을 -5 dB로 맞추는 값 → **+8.15 dB** (조절 트랙만 바꾸고 다른 트랙을 더한 소리 기준으로 계산)
  4. A2 두 클립에 **선택적 제한**: 입력 증폭 +8.15 dB (값 = (dB+40)/60 = 0.8025), 최대 진폭 -6 dB (값 0.94). 나머지 기본값
  5. 전체를 WAV로 내보내 `verify.py`로 검증 → 미터 기준 구간 최고값 중앙값 -5.6 dB, -4~-6 dB 안 341/368 (93%)
- 사용자 피드백 (원문): "좋아. 결과물이 아주좋아. 학습해줘"
- 다음에 적용할 점:
  - 말소리는 이 두 단계(게인 → 선택적 제한 -6 dB)로 끝낸다. 구간별 키프레임은 쓰지 않는다
  - 게인은 오디오 게인을 스크립트로 못 바꾸므로 선택적 제한의 입력 증폭에 넣는다
  - 결과는 미터 기준(구간 실제 최고값)으로 보고한다
  - 다른 트랙(B캠 등) 때문에 0 dB에 닿는 곳은 리포트에 시간과 함께 남긴다
