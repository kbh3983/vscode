## [A3~A6] 말소리: 게인으로 평균 + 선택적 제한 -6 dB (2026-10-06, 261006_최박사_운동법_AI / 옆구리살_가편)
- 상황: 22분 인터뷰 시퀀스, A1 B캠(작음, 그대로 둠) + A2 C캠(C0027·C0028, '좌측과 우측 채우기'로 왼쪽 채널만 들림). 자막 없음, 배경음악·효과음 없음. 사용자 지시로 A2 트랙만 조절
- 한 방법 / 사용한 값:
  1. 시퀀스 복제 (`옆구리살_가편_오디오2`)
  2. `levels.py`로 측정: 말 구간(에너지로 자동 검출, 0.3초 이상 368개)의 최고값(상위 1% 제외) 중앙값 -13.0 dB. 클립의 채널 이펙트(`"fill": "L"`)를 반영해 실제 들리는 소리 기준으로 측정
  3. 게인 = 중앙값을 -5 dB로 맞추는 값 → **+8.15 dB** (조절 트랙만 바꾸고 다른 트랙을 더한 소리 기준으로 계산)
  4. A2 두 클립에 **선택적 제한**: 입력 증폭 +8.15 dB (값 = (dB+40)/60 = 0.8025), 최대 진폭 -6 dB (값 0.94). 나머지 기본값
  5. 전체를 WAV로 내보내 `verify.py`로 검증 → 미터 기준 구간 최고값 중앙값 -5.6 dB, -4~-6 dB 안 341/368 (93%)
- 사용자 피드백 (원문): "좋아. 결과물이 아주좋아. 학습해줘"
- 다음에 적용할 점:
  - 말소리는 이 두 단계(게인 → 선택적 제한 -6 dB)로 끝낸다. 구간별 키프레임은 쓰지 않는다
  - 게인은 오디오 게인을 스크립트로 못 바꾸므로 선택적 제한의 입력 증폭에 넣는다
  - 결과는 미터 기준(구간 실제 최고값)으로 보고한다
  - 다른 트랙(B캠 등) 때문에 0 dB에 닿는 곳은 리포트에 시간과 함께 남긴다

## [모노 사운드] 두 출연자 핀마이크(좌·우)를 양쪽 똑같이, 두 사람 같은 크기로 (2026-10-09, 260929_최박사_운동법3 / 목교정기_종편)
- 상황: A1 = C0022, 두 출연자에게 마이크를 하나씩 달아 좌·우 채널에 따로 녹음 (좌우 상관 0.01, 말할 때 자기 마이크 쪽이 약 10 dB 큼). A2 = B캠(싱크용, 영상에서 안 씀), A3 = 효과음. 사용자 지시로 처음 30초만 새 시퀀스(`목교정기_종편_오디오_30초`)
- 한 방법 / 사용한 값:
  1. 원본 복제 → 30초에서 모든 트랙 razor, 이후 클립 삭제
  2. 원본 A1 좌·우를 따로 분석해 말하는 사람 구분 → L+R 1:1이면 두 사람 차이 0.03 dB (비율 보정 불필요)
  3. A1 18개 클립: 기존 선택적 제한(−5 dB)·좌측과 우측 채우기 바이패스 → **채널 혼합기** 네 값 모두 1(+100%) → **선택적 제한** 새로 추가: 입력 증폭 +4.38 dB(0.7397), 최대 진폭 −6 dB(0.94)
  4. 검증: 좌·우 RMS −18.13 / −18.13 dB, 두 사람 미터 최고값 중앙값 −6.00 / −6.00 dB, 상위 1% 제외 차이 0.5 dB
- 사용자 피드백 (원문): "결과가 너무좋다. 지금 이 방식을 학습하자. 에이전트는 오디오 에이전트에 학습시켜줘."
- 다음에 적용할 점: "모노"/"모노 사운드" 요청이 오면 [playbook_모노.md](playbook_모노.md)를 그대로 따른다.

## [모노 사운드] 전체 구간 — 두 사람 비율 보정 (2026-10-09, 260929_최박사_운동법3 / 목교정기_종편 → 목교정기_종편_모노)
- 상황: 10초 시험(`목교정기_종편_모노_10초`) 후 전체 진행. A1 = C0022 131개(0~384초) + 롱폼_엔딩영상 1개. 전체로 보니 왼쪽 마이크 주인이 대부분 말함
- 한 방법 / 사용한 값:
  1. 비율을 **전체 구간**으로 다시 계산: 1:1이면 오른쪽 주인이 1.94 dB 큼 → 왼쪽 100% : 오른쪽 77% (채널 혼합기 `[2]=1, [3]=0.885, [10]=1, [11]=0.885`) → 차이 0.04 dB
  2. 게인 +7.40 dB (섞은 소리 피크 중앙값 −12.40 → −5), 선택적 제한 입력 증폭 0.79, 최대 진폭 0.94
  3. C0022 클립에만 적용, 엔딩 영상은 그대로. A2 음소거, A3 효과음 켜 둠
  4. 검증: 좌·우 RMS −18.38 / −18.38 dB, 두 사람 미터 최고값 −6.00 / −6.00, 상위 1% 제외 차이 0.3 dB, 말 구간 97/100이 −4~−6 dB, −6 dB 넘는 곳은 효과음 위치뿐
- 사용자 피드백 (원문): "아주좋아. 학습해."
- 다음에 적용할 점: 시험 구간(10초)의 비율을 그대로 쓰지 말고, 전체 진행 때 **전체 구간으로 두 사람 비율과 게인을 다시 계산**한다. A1에 다른 소스가 섞여 있으면 두 마이크 녹음 원본 클립에만 적용한다

## [모노 사운드] 여러 시퀀스 일괄 — 스크립트화 (2026-10-09, 260929_최박사_운동법3 / 열린 4개 시퀀스)
- 상황: 틀어진골반·하체루틴·옆구리살·자세교정 `_종편` 4개를 한 번에. 모두 A1 = C캠 두 마이크 + 롱폼_엔딩영상, A2 = B캠, A3 비어 있음. 사용자가 바로 전체 지시(10초 시험 없음)
- 한 방법 / 사용한 값:
  1. ExtendScript로 각 시퀀스 오디오 클립 목록 → `work/모노/<시퀀스>.json`
  2. `scripts/audio/mono.py`: 원본 파일마다 두 마이크 확인(엔딩 영상 상관 0.94 → 자동 제외, 옆구리살 C0027+C0028 둘 다 포함), 전체 구간으로 비율·게인 계산 → `_plan.json`
  3. 원본 복제 → `<시퀀스>_모노` → `scripts/audio/apply_mono.jsx`로 B캠 트랙 음소거 + C캠 클립에 채널 혼합기·선택적 제한
  4. 내보내기 → `scripts/audio/mono_verify.py`
  - 비율 왼쪽 100 : 오른쪽 74 / 87 / 91 / 69, 게인 +8.02 / +8.75 / +7.68 / +6.15 dB
  - 결과: 4개 모두 좌·우 RMS 동일, 두 사람 미터 최고값 −6.00 / −6.00 dB, 말 구간 98~100%가 −4~−6 dB, −6 dB 넘는 곳 없음
- 사용자 피드백 (원문): "작업 잘 됐어, 결과물 깔끔하다. 학습해줘"
- 다음에 적용할 점: 여러 시퀀스는 [playbook_모노.md](playbook_모노.md)의 "스크립트 (여러 시퀀스 일괄)" 순서대로 한다. 대상 시퀀스는 매번 다시 읽는다 (같은 이름이라도 트랙 구성이 바뀌어 있을 수 있음 — 자세교정_종편) 사용자 작업 규칙 — 처음 10초 먼저 별도 시퀀스, 원본 시퀀스는 건드리지 않음, A1만 작업, 다른 음성 트랙은 음소거만(지우지 않음)

## [회고] 콧바람 노이즈 → 그 구간 채널 끄기 (2026-10-14, 하체루틴 최종본)
- 상황: 사용자가 하체루틴 A캠 14클립에 채널 채우기(13개 R 끔, 1개 L 끔) — 이유: "운동 시 자연스러운 숨소리가 아닌, 콧바람 같은 노이즈가 들어가서 그 출연자의 오디오를 끈 거야"

- 사용자 피드백 (원문): "9번은 승인할게. 초반에는 후보를 주면 내가 승인한 뒤, 데이터가 어느정도 쌓이면 그 때는 자동화 하는 방향으로 가자."
- 다음에 적용할 점: 두 사람 핀마이크 영상이면 `nose_noise.py`로 후보 → 사용자 승인 → 그 구간만 채널 채우기. 결정은 `nose_choices.md`에. 채널 채우기를 스크립트로 넣는 방법은 첫 작업 때 시험 (QE 오디오 효과)
