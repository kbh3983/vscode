# 오디오 에이전트

## 역할
시퀀스 안의 소리를 **종류별 목표 음량**에 맞춘다. 말소리·배경음악·효과음이 서로 묻히거나 튀지 않게 한다.

| 종류 | 목표 음량 (사용자 지정, 2026-10-05) |
|---|---|
| **말소리** (대사) | **-4 ~ -6 dB** |
| **배경음악** (BGM) | **-18 ~ -21 dB** |
| **효과음** (SFX) | **-10 ~ -12 dB** |

- 하는 것: 오디오 클립 종류 구분, 음량 측정, 클립 음량 조절, 문장마다 크기가 들쭉날쭉한 말소리 고르게 맞추기, 말소리 나올 때 배경음악 낮추기(덕킹, 선택), 결과 측정·리포트
- 하지 않는 것: 잡음 제거·EQ 같은 음질 보정(요청 시 별도), 배경음악·효과음 고르기·배치, 컷 편집

> 측정 기준(아래 "미결")이 정해지기 전까지 dB는 **Premiere 오디오 미터에 보이는 최고 음량(피크, dBFS)** 으로 해석한다. 편집자가 미터를 보며 맞추는 값과 같다.

---

## 1. 원칙
1. **원본 파일은 건드리지 않는다.** Premiere 타임라인의 클립 음량(볼륨)·키프레임·이펙트로만 조절한다
2. **작업 전 시퀀스를 복제**하고 복제본에서 작업한다 (`<시퀀스>_오디오`)
3. 측정은 **실제 오디오에서** 한다 (ffmpeg로 클립의 사용 구간을 읽어 계산). 짐작으로 값을 넣지 않는다
4. 목표 범위의 **가운데**를 겨냥한다 (말소리 -5 dB, 배경음악 -19.5 dB, 효과음 -11 dB). 범위 안에만 들면 된다
5. 클립을 조절한 뒤 **다시 측정해 범위 안인지 확인**한다. 범위를 벗어난 클립은 리포트에 남긴다
6. 소리가 깨지지(클리핑) 않게 한다: 어떤 경우에도 최고 음량 0 dB를 넘지 않게

---

## 2. 클립 종류 구분
| 종류 | 판단 기준 (순서대로) |
|---|---|
| 말소리 | `촬영본` 빈의 클립 (카메라 내장 오디오) |
| 배경음악 | `자료` 빈 안의 `BGM` 하위 빈, 또는 파일 이름에 bgm·music |
| 효과음 | `자료` 빈 안의 `효과음`(SFX) 하위 빈, 또는 파일 이름에 sfx·효과음 |
| 판단 불가 | 사용자에게 묻는다 (추측해서 조절하지 않는다) |

---

## 3. 작업 단계

| 단계 | 하는 일 |
|---|---|
| **A1 확인** | 대상 시퀀스의 오디오 트랙·클립 목록, 각 클립의 원본 파일·사용 구간(소스 In/Out)·현재 볼륨 읽기 |
| **A2 종류 구분** | 2장 기준으로 말소리 / 배경음악 / 효과음 분류. 판단 불가는 질문 |
| **A3 측정** | ffmpeg로 각 클립의 사용 구간 오디오를 읽어 최고 음량(피크)과 평균 음량 측정. 말소리는 **문장(말 구간)마다** 따로 측정 |
| **A4 조절** | 말소리 (사용자 지정, 2026-10-06): ① **게인으로 평균을 맞춤** (말 구간 최고값 중앙값 → -5 dB) ② **선택적 제한으로 최대 -6 dB**. 구간별 키프레임은 쓰지 않음 (비효율, 사용자 거절) |
| **A5 덕킹 (선택)** | 말소리가 나오는 구간에 배경음악을 범위 아래쪽(-21 dB)으로, 말이 없는 구간은 위쪽(-18 dB)으로 → `setup_ducking` |
| **A6 검증** | 조절 후 다시 측정 → 범위 밖 클립·구간 표시 |
| **A7 저장·리포트** | 프로젝트 저장, `report.md` (클립별 측정값·조정값·결과) |

### 멀티캠 말소리 주의
싱크 시퀀스는 A캠·B캠 오디오 트랙이 **모두 켜져 있어**(싱크 에이전트 규칙) 같은 말이 두 번 겹쳐 들린다. 둘을 합친 음량은 하나일 때보다 커진다.
- 측정·조절은 **최종으로 들리는 소리(켜져 있는 트랙의 합)** 기준으로 한다
- 컷편집에서 한 카메라 오디오만 쓰기로 정해지면 그 기준으로 다시 맞춘다 (미결)

---

## 4. 입력 / 출력
**입력**: Premiere 시퀀스 (대상 시퀀스 이름을 사용자가 지정)
**출력** (`work/<프로젝트명>/audio/`):
| 파일 | 내용 |
|---|---|
| `levels.json` | 클립별 종류, 측정값(조절 전·후), 적용한 조정값·키프레임 |
| `report.md` | 사용자용 요약, 범위 밖 항목 |

Premiere: `시퀀스/<시퀀스>_오디오` (조절된 복제본), 저장

---

## 5. 사용 도구
- Premiere Pro MCP: `list_sequence_tracks`, `get_clip_properties`(소스 구간), `duplicate_sequence`, `adjust_audio_levels`(클립 볼륨 dB), `add_audio_keyframes`, `setup_ducking`, `apply_audio_effect`(리미터·컴프레서), `save_project`
- ffmpeg: 클립 구간 음량 측정 (`astats` 피크·RMS, 필요 시 `ebur128` LUFS)
- `scripts/audio/levels.py` (A3 측정, 자막 없으면 에너지로 말 구간, 게인 계산) → Premiere 적용 → `Waveform Audio 48kHz 16-bit.epr`(Premiere systempresets)로 내보낸 WAV를 `verify.py` (A6)
- `tracks.json`의 `"fill": "L"` = 클립에 '좌측과 우측 채우기'(왼쪽 채널을 양쪽으로)가 걸려 있음. 측정 전에 클립 채널 이펙트를 꼭 확인
- 클립 '오디오 게인'은 스크립트로 못 바꿈 (QE `staticClipGain` 읽기 전용) → 선택적 제한의 **입력 증폭**에 게인을 넣음 (리미터 앞단이라 소리는 같음)
- Premiere 값 변환: 선택적 제한(하드 리미터) 최대 진폭 dB = (값−1)×100, 입력 증폭 dB = 값×60−40. 볼륨 레벨 = 10^((dB−15)/20). 클립 이펙트는 삭제 API가 없음(바이패스만). `execute_extendscript`는 `code` 인자 + `return`
- 리미터 상한이 -6 dB이므로 결과 확인은 **미터 기준(구간 실제 최고값)** 으로 본다. 상위 1% 제외 값은 상한보다 1~2 dB 낮게 나옴

---

## 6. 작업 절차 요약
1. **준비**: `criteria.md` → `learnings.md` → `failures.md` → 최근 `log/`
2. 대상 시퀀스 확인 → 복제 → A1~A3
3. 사전 확인 (초기 운영 기간): 클립별 측정값과 적용할 조정값을 보여 주고 승인 → A4~A6
4. 저장, 리포트, 사용자 확인 → 피드백 기록
