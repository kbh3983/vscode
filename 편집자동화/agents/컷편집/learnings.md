## [C6·C2·C1] 0~5:50 리뷰에서 승인된 컷 (2026-10-06, 261006_최박사_운동법_AI / 옆구리살_가편_오디오2)
- 상황: 22분 운동 영상(최박사 + PD), Cutback SRT 정렬로 단어 시간 확보. 사용자가 `옆구리살_가편_오디오2_컷`의 0~5:50을 리뷰하고 문제 있는 곳에만 V3 그래픽 텍스트로 메모
- 한 방법 / 사용한 값 (메모가 없어 승인된 것):
  - C6: 녹화 시작~오프닝 첫 테이크 직전(0~115초)의 매트·카메라 세팅, 썸네일·제목 의논을 통째로 비활성화
  - C2: 오프닝 1차 후 "시선 뺏겨서 다시 할까요? 처음부터" 대화, "됐나요? 오케이", 중단된 시작("첫 번째는 간단하게"), 전화 통화를 한 구간으로 묶어 삭제. 경계는 남길 문장의 정렬 단어 시작 −2프레임 / 끝 +6프레임
  - C1: 운동 **자세를 잡는 장면**(볼 위에 앉기, 손 위치 설명)의 0.7초 이상 무음은 0.3초만 남기고 줄임 (193초, 207초)
  - C7: 오프닝 두 테이크는 모두 남기고 마커로 표시
- 사용자 피드백 (원문): "5분 50초 이전에 V3 트랙에 아무것도 없는거는 너무 잘한거야. 5분 50초 이전에 V3 트랙에 아무것도 없으면서 비활성화되어있는거는 필요없는게 확인된거니까 지워도돼."
- 다음에 적용할 점:
  - 촬영 준비·제목 의논·통화·"다시 할까요" 류는 같은 기준으로 자른다
  - 자세 잡는 장면의 무음은 줄여도 된다 (단, 동작이 시작되면 무음을 자르지 않는다 — failures.md 참고)
  - 사용자가 리뷰로 확인한 삭제는 다음 시퀀스에서 클립을 지운다(비활성화 대신)

## [실행] 지운 클립의 빈 구간 닫기 (2026-10-06, 261006_최박사_운동법_AI / 옆구리살_가편_오디오2_컷2)
- 상황: 확인된 삭제 5구간(합계 4948프레임, 165초)을 지운 뒤 4개 트랙에 같은 위치의 빈 구간이 남음
- 한 방법 / 사용한 값: 빈 구간 목록(프레임)을 구해, 각 클립을 "그 클립 앞에서 닫힌 빈 구간 합계"만큼 `trackItem.move(-오프셋)`으로 당김 (상대 이동, 연결된 클립은 따라오지 않아 트랙마다 따로). 마커도 같은 양만큼 `m.start`/`m.end`(숫자 초)로 당김. 확인: 모든 트랙 빈 구간 0, 4개 트랙 클립 위치 동일, 21:57 → 19:11
- 사용자 피드백 (원문): "빈구간 제거해줘. 이것도 학습해라. 다음부터는 제거해"
- 다음에 적용할 점: 클립을 지우는 작업(X)에는 항상 빈 구간 닫기를 함께 한다 — `scripts/cut/apply_ops.jsx`가 X 다음에 자동으로 한다. 비활성화(D)한 클립은 확인 전이라 그대로 둔다
