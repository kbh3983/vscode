# 컷편집 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값.

## 타임라인 표시 (색 라벨)
| 용도 | 색 | 상태 |
|---|---|---|
| 비활성화한 삭제 구간 (C1~C6, C8) | 빨강 | 초안 |
| 사용자 확인 필요 (`review`) | 노랑 | 초안 |
| 재촬영 테이크 그룹 (C7) | 그룹마다 다른 색 (빨강·노랑 제외) | 초안 |

## 필러 후보 (C4)
항상 후보: 음, 어, 으, 아(문장 앞)
문맥 판단 후보: 그, 저, 이게, 뭐지, 약간, 막, 이제, 뭐랄까, 그러니까
> "약간", "막", "그러니까"는 실제 의미로 쓰일 때가 많으므로 문장 의미가 유지되는지 확인

## 말더듬 패턴 (C5)
- 같은 어절 반복: "이제, 이제부터", "그 그 그게"
- 미완성 단어 + 완성 단어: "사, 사람들이"

## 촬영 잡담 신호 (C2, C3, C6)
- "다시 갈게요", "다시 할게요", "한 번 더", "컷", "레디", "액션", "녹화 돼?", "잠깐만요"
- 화면 밖 목소리 (메인 화자가 아닌 화자)
- 웃음 + 말 중단 후 같은 문장 재시작 → NG 가능성 높음
