# 컷편집 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값.

> **적용 범위 (2026-10-14 사용자 승인):** **표시 없는 줄 = 공통** (영상 종류와 상관없음). `[운동]` = 운동법 영상이면 채널과 상관없이, `[최박사]` = 최박사 채널의 촬영 환경·화면 구성·템플릿, `[설명]` = 설명·상담형(포인트 genre), `[강연]` = 강연 (2026-10-14 운동/최박사 나눔) (`docs/영상종류_분류안.md`).

## 필러 후보 (C4)
항상 후보: 음, 어, 으, 아(문장 앞)
문맥 판단 후보: 그, 저, 이게, 뭐지, 약간, 막, 이제, 뭐랄까, 그러니까
> "약간", "막", "그러니까"는 실제 의미로 쓰일 때가 많으므로 문장 의미가 유지되는지 확인

### [최박사] 습관적인 "네" (C4)
| 항목 | 값 | 상태 |
|---|---|---|
| 대상 | 최박사가 습관적으로 하는 **"네"**(단독·문장 앞·문장 안) — 찾아서 지움 | 확정 (사용자: "최박사 영상은 최박사가 습관적으로 네 라는 말을 많이 쓰거든, 그래서 그 말이 있는 구간은 찾아서 없애줘. 초반부터 있어서 내가 몇군데 없애다가, 반복적일 것 같아서 공유해" (2026-10-22 누워서_컷편집)) |
| 지우는 범위 (운동 중 아님) | 사용자 방식: "네"와 **앞뒤 쉼까지** — 앞 말 끝 뒤 0.2초는 남기고, 다음 말 시작 0.1초 앞까지 (사용자 0:19.7·0:25.3 직접 수정) | 확정 (위 근거) |
| 지우는 범위 (운동 중) | 동작 화면이 덜 끊기게 "네" 소리만 (±0.04초), 점프컷 마커 → 컷전환 때 B캠으로 가림 | 확정 (사용자: "잘했어, 컷전환도 이어서 진행해줘." 2026-10-22) |
| 경계 | "네"는 정렬이 짧고 자주 실패 → 실제 소리 덩어리(바닥 잡음 +12 dB)와 앞뒤 쉼으로 경계, 붙어 있으면 주변보다 6 dB 조용한 지점(±0.15초). 정렬 안 된 "네"는 자막 줄 단위로 찾음. 지우기 전 그 구간만 받아쓰기해서 "네"인지 확인 (아니면 마커) | 확정 (사용자: "잘했어, 컷전환도 이어서 진행해줘." 2026-10-22) |
| **찾는 범위 (2026-10-26)** | "네"는 **남길 구간뿐 아니라 확인 필요·비하인드 후보·맨 뒤 덧붙인 설명까지 전 구간**에서 찾는다 (나중에 옮겨 쓰는 구간에도 남지 않게). 정렬 안 된 자막 줄의 "네"도 소리 덩어리로 찾고, 컷편 최종본을 다시 받아쓰기해 **남은 "네"를 한 번 더 검사**한 뒤 보고 | 확정 (사용자: "이대로 마무리 할게, 다음에는 네라는 말습관은 좀 더 면밀히 컷편집하자." (2026-10-26 누워서 — 맨 뒤 팁을 마지막 운동 뒤로 옮기자 첫머리 "네"가 남아 있었음)) |

## 말더듬 패턴 (C5)
- 같은 어절 반복: "이제, 이제부터", "그 그 그게"
- 미완성 단어 + 완성 단어: "사, 사람들이"

## 촬영 잡담 신호 (C2, C3, C6)
- "다시 갈게요", "다시 할게요", "한 번 더", "컷", "레디", "액션", "녹화 돼?", "잠깐만요", "잠시만요. 다시" (2026-10-26 체어 — 확인 표시로만 남기지 말고 위 "NG 신호 뒤 다시 하기" 규칙대로 처리)
- 화면 밖 목소리 (메인 화자가 아닌 화자)
- 웃음 + 말 중단 후 같은 문장 재시작 → NG 가능성 높음
