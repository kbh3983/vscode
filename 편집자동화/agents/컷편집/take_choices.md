# 재촬영 테이크 선택 기록 (C7)

사용자가 여러 테이크 중 하나를 고를 때마다 **왜 그 테이크를 골랐는지** 기록한다.
쌓인 이유는 아래 "선택 이유 패턴"으로 정리하고, 같은 이유가 반복되면 `criteria.md`의 테이크 추천 기준으로 올릴 것을 사용자에게 제안한다.

- 이유는 **사용자 원문 그대로** 적는다. 에이전트가 짐작한 이유를 적지 않는다
- 사용자가 이유를 말하지 않았으면 "이유 미입력"으로 적고, 패턴 집계에서 뺀다

---

같은 분류의 이유가 **3회 이상** 나오면 `criteria.md` "테이크 추천 기준"으로 올릴지 사용자에게 제안한다.

분류 예시 (실제 이유에 맞춰 새로 만든다): 전달력(또렷함·속도), 표정·시선, 내용 완성도, 에너지·톤, 실수 없음, 길이, 동작 정확도

## 선택 기록

형식:
```
### YYYY-MM-DD · 프로젝트명 · 테이크 그룹 N
- 내용: (어떤 말을 하는 테이크들인지 한 줄)
- 후보:
  | 테이크 | 타임코드 | 길이 | 에이전트가 본 특징 |
  |---|---|---|---|
  | T1 | | | (필러 수, 말 속도, 끊김 여부 등 측정값만) |
  | T2 | | | |
- 사용자 선택: T?
- 선택 이유 (원문): "..."
- 분류: (위 분류 중 하나 이상)
- 에이전트 추천과 일치 여부: (추천을 냈을 때만) 일치 / 불일치 — 불일치면 무엇을 놓쳤는지 한 줄
```

(아직 없음)
