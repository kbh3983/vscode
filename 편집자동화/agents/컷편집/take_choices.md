# 재촬영 테이크 선택 기록 (C7)

사용자가 여러 테이크 중 하나를 고를 때마다 **왜 그 테이크를 골랐는지** 기록한다.
쌓인 이유는 아래 "선택 이유 패턴"으로 정리하고, 같은 이유가 반복되면 `criteria.md`의 테이크 추천 기준으로 올릴 것을 사용자에게 제안한다.

- 이유는 **사용자 원문 그대로** 적는다. 에이전트가 짐작한 이유를 적지 않는다
- 사용자가 이유를 말하지 않았으면 "이유 미입력"으로 적고, 패턴 집계에서 뺀다

---

## 선택 이유 패턴 (집계)
같은 분류의 이유가 **3회 이상** 나오면 `criteria.md` "테이크 추천 기준"으로 올릴지 사용자에게 제안한다.

| 분류 | 횟수 | 대표 원문 | criteria 반영 |
|---|---|---|---|
| 내용 정확(호칭·표현) | 1 | "최박사가 맞는 표현이고" | - |
| 매끄러움(오케이 컷 가능성) | 1 | "매끄러운 게 오케이 컷일 확률이 높아서" | - |

분류 예시 (실제 이유에 맞춰 새로 만든다): 전달력(또렷함·속도), 표정·시선, 내용 완성도, 에너지·톤, 실수 없음, 길이, 동작 정확도

---

## 선택 기록

형식:
```
### YYYY-MM-DD · 프로젝트명 · 테이크 그룹 N
- 내용: (어떤 말을 하는 테이크들인지 한 줄)
- 후보:
  | 테이크 | 타임코드 | 길이 | 에이전트가 본 특징 |
  |---|---|---|---|
  | T1 | | | (필러 수, 말 속도, 끊김 여부 등 측정값만) |
  | T2 | | | |
- 사용자 선택: T?
- 선택 이유 (원문): "..."
- 분류: (위 분류 중 하나 이상)
- 에이전트 추천과 일치 여부: (추천을 냈을 때만) 일치 / 불일치 — 불일치면 무엇을 놓쳤는지 한 줄
```

### 2026-10-20 · 260929_최박사_운동법4 누워서 하는 최고의 서킷트레이닝 · 테이크 그룹 1
- 내용: 오프닝 인사 + 오늘 운동(누워서 하는 스틱 서킷) 소개
- 후보:
  | 테이크 | 타임코드 | 길이 | 에이전트가 본 특징 |
  |---|---|---|---|
  | T1 | 00:00:31–00:00:54 | 23초 | "최 강사입니다"로 소개, 중간에 PD에게 묻는 말("이거 이거 어때요?"), 말더듬("서킷 서킷 트레이닝 프로그램 트레이닝 프로그램을") |
  | T2 | 00:00:58–00:01:48 | 50초 | "최 박사입니다"로 소개, 끝까지 이어짐 (재시작 2곳은 C8로 따로 자름) |
- 사용자 선택: T2
- 선택 이유 (원문): "t2로 하자. 최박사가 맞는 표현이고, 매끄러운 게 오케이 컷일 확률이 높아서 선택했어. 참고해줘."
- 분류: 내용 정확(호칭·표현), 매끄러움(오케이 컷 가능성)
- 에이전트 추천과 일치 여부: 추천 없음 (기준 생기기 전). T1 비활성화
