## 2. 꼭 지킬 것 (사용자 결정)
- 자막·제목 = **캡션 트랙** (png 금지). 제목은 "캡션 트랙에 그대로" — 그래픽 업그레이드는 사용자가 원할 때만
- 대사 자막은 **안내 박스 구간에도** (겹쳐도 됨) — 자막이 비면 마가 뜬다
- 한 줄 **15자 이하**, 템포·쉼·맥락에서 끊기
- 하단 고정 안내 = 단톡방 → 플레오라, 마지막 6초 비움, y 1555~1672
- **쉼을 일괄로 자르지 않는다** (동작 시연일 수 있음 — 물어본다)
- 최종 시퀀스 하나만 남기고 정리. 지우면 안 되는 것: `<롱폼>_숏폼소스_샷`(V1이 씀), `최박사_숏폼_템플릿_v2`, `둔근_최박사_운동법1_숏폼소스`(템플릿이 씀)

## 3. 함정 (다시 겪지 않게)
| 증상 | 원인 | 해결 |
|---|---|---|
| 빈 자막 트랙 C1·C2가 남아 지울 수 없음 | **자막 트랙은 스크립트로 지우기·고치기·세기 불가**(시퀀스 기능은 createCaptionTrack 하나), 복제하면 따라옴 | 자막 트랙은 최종 시퀀스에서 **한 번만** 만든다. 틀리면 새 시퀀스를 만들어 옮김(`copy_clean.jsx`) |
| 제목을 자막 트랙으로 넣으면 대사 자막과 동시에 안 보일 때가 있음 | 프리미어 재생은 자막 트랙을 하나씩 보여 줌 | 사용자가 트랙 표시 전환 / 업그레이드 |
| 프리미어 자체 텍스트(그래픽)를 스크립트로 못 만듦 | 프리미어 템플릿은 문구 칸이 없고 소스 텍스트를 읽고 쓸 수 없음(UXP도 같음) | 비디오 트랙 텍스트가 꼭 필요하면 AE 템플릿(`숏폼_상단제목_AE`) |
| 빈(bin)이 숏폼마다 새로 생김 (`숏폼_첫작업` 15개) | `findItem`은 빈을 못 찾음 | `findBin` 사용 |
| 조각이 0초부터 들어감 / 213초까지 늘어남 | 소스 인/아웃이 앞 조각 아웃보다 뒤면 무시됨, 1프레임 조각도 무시됨 | 매번 clearIn/Out 먼저, 2프레임 이하 조각은 옆에 붙임 |
| 조각 사이 1프레임 검은 화면 | 초→프레임 반올림 | 앞 클립 끝을 다음 시작까지 늘림(`fill_gaps.jsx`, rebuild_v1에 포함) |
| A캠 인물이 양 끝에 잘림, 헤드룸 없음 | 롱폼 펀치인을 그대로 가져와 1:1로 또 자름 | 4K 원본 전체로 펴고 숏폼에서 새로 프레이밍(7단계) |
| 하단 안내가 레퍼런스보다 94px 낮음 | 검정 영역 가운데에 둠 | 예시 실측 y 1555~1672 (`make_assets.bottom`) |
| 자막 줄이 26자까지 길어 잘림 | 공백 뺀 14자 + 짧은 줄 합치기 | 공백 포함 15자 DP (`resub.py`) |
| 프레임 내보내기 실패 | 열려 있지 않은 시퀀스 activeSequence·슬래시 경로 | openSequence 후 지정, 경로는 역슬래시 (`export_frames.jsx`) |
| 같은 이름 srt를 새로 만들어도 옛 것이 들어감 | 빈 안 같은 이름 항목을 재사용 | 새 srt는 새 빈 이름으로 가져옴 (`SRT_BIN`, `BINS`) |
| 자막이 말보다 먼저/늦게 뜸 (최대 1.5초) | 롱폼 받아쓰기 단어 시간을 숏폼으로 옮겨 씀 — whisper는 쉼 뒤 첫 단어 시작을 쉼 쪽으로 당기고, 쉼을 단어 길이에 붙임("그냥" 1.7초) | 숏폼 오디오를 다시 받아써서 맞춤(8-1). 확인은 사용자 수정본 비교 |
| 자막을 읽을 수 없음 | 스크립트 API에 자막 읽기 없음 | 프로젝트 파일(.prproj, gzip XML)에서 CaptionDataClipTrackItem 시간 + base64 글자 읽기 (`read_captions.py`) |
| MCP 45초 시간 초과 | 숏폼 여러 개를 한 번에 | 한 번에 1~3개, 남은 것을 찾아 이어서 하는 스크립트로 |
