# 숏폼 — 잘 안된 결과 (하지 말 것)

사용자가 불만족한 결과. **같은 실수를 피할 때만** 참고한다. 좋은 방법의 근거로 쓰지 않는다.

형식:
```
## 제목 (날짜, 롱폼 → 숏폼)
- 상황:
- 한 방법 / 사용한 값:
- 무엇이 문제였나 (사용자 피드백 원문):
- 하지 말 것:
```

---

(아직 없음)

참고 (사용자 경험): 클린본을 따로 내보내서 쓰는 방식은 비효율적이었음 → 롱폼 클립 복사로 (criteria 영상 소스)

## 첫 작업에서 다시 만든 것들 (2026-10-14~16, 숏폼 15개)
- 상황: 같은 15개를 시퀀스 6번 다시 만듦 (`_텍스트` → `_텍스트2` → `_샷` → `_정리` → `_정리2`)
- 무엇이 문제였나 (사용자 피드백 원문): "숏폼 안에 들어간 폰트가 png 이미지로 다 들어가 있는데, 수정이 안 되서" / "텍스트가 긴 것들은 잘리네" / "A캠은 인물이 정 가운데 있어야 해 머리는 잘리면 안 되고" / "자막 길이가 말 끝나면 사라져서 자막이 비더라고 … 마가 뜨면 안 되거든" / "하단 안내 이미지 위치가 레퍼런스보다 낮은 것 같은데" / "c1,c2 … 안쓰는 트랙 삭제하고 싶어서"
- 하지 말 것: 자막·제목 png / 공백 빼고 세는 14자+줄 합치기 / 롱폼 펀치인 그대로 1:1 크롭 / 안내 박스 구간 자막 빼기 / 하단 안내를 실측 없이 배치 / 비교용 자막 트랙 여러 개·템플릿 복제로 빈 자막 트랙 남기기 / 쉼을 일괄로 자르기(동작 시연일 수 있음)
