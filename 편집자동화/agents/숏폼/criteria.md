# 숏폼 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값 (예시 4개 분석에서 나옴).

> **적용 범위:** **표시 없는 줄 = 공통**, `[운동]` = 운동법 영상이면 채널 상관없이, `[최박사]` = 최박사 채널 전용 (`agents/README.md` 영상 종류).
