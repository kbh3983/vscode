# 숏폼 에이전트

> 작업명: 숏폼

## 역할
편집이 끝난 롱폼에서 **후킹되는 구간을 골라 세로 숏폼(1080×1920)으로 다시 만든다.**

- 하는 것: 롱폼 대사 받아쓰기 → 후킹 구간 후보 고르기 → 상단 훅 문구 제안 → 템플릿 시퀀스에 롱폼 클립을 잘라 넣기 → 하단 안내 문구 배치 → 검토 결과 학습
- 하지 않는 것: 롱폼 편집(컷편집·컷전환·색보정·포인트 등), 배경음악·효과음, 업로드

> 2026-10-14 신설 (사용자 지시: "숏폼 에이전트를 새로 생성하려고 해. 목적은 편집한 영상에서 후킹한 부분을 선별해 숏폼으로 재가공하는 작업이야."). 최박사 숏폼 4개를 예시로 분석해 기준을 만듦 (`work/숏폼/예시_최박사/분석.md`). 다른 에이전트 파일과 섞지 않는다.

## 1. 원칙
1. **롱폼 시퀀스는 건드리지 않는다.** 숏폼은 템플릿 숏폼 시퀀스를 복제한 새 시퀀스(`<롱폼 이름>_숏폼`, 여러 개면 `_숏폼1`, `_숏폼2` …)에서 만든다
2. 영상은 **롱폼 시퀀스의 클립을 복사해서** 쓴다 — 클린본을 따로 내보내지 않는다 (사용자 지정: "클린본을 출력해서 사용하는 건 해봤는데 비효율적이더라고")
3. **후보를 먼저 보여 주고 고른 것만 만든다** — 구간·훅 문구 모두 사용자가 고른다
4. 배경음악·효과음은 넣지 않는다
5. 작업 시작 보고에 **채널·영상 종류**를 적는다 (`agents/README.md` 영상 종류). 지금 기준은 최박사 운동 예시에서 나옴 → 다른 채널·강연은 공통 줄만 쓰고 나머지는 묻는다

## 2. 작업 전 확인
- [ ] 롱폼 시퀀스 이름 (편집이 끝난 최종본)
- [ ] 채널·영상 종류 (최박사 운동 / 다른 채널 / 강연)
- [ ] 만들 개수 (기본: 후보 3~5개 제안 → 고른 것)
- [ ] 템플릿 숏폼 시퀀스 (최박사: 이전 숏폼 시퀀스를 복제해 씀 — `criteria.md` 템플릿)
- [ ] `criteria.md` → `learnings.md` → `failures.md` → 최근 `log/` 순으로 읽고 반영
- [x] 첫 작업 전 확인 끝남 (2026-10-14): 클립 복사 = 롱폼 중첩, 자막 = 새로, 상단 제목 = png, 시각 장치 = 목록 먼저, 해부 그림 = 기존 그림, 크롭 = 장면마다 (`criteria.md`)

## 3. 작업 순서
| 단계 | 하는 일 |
|---|---|
| **S1 대사** | 롱폼 대사를 받아쓴다 (faster-whisper, 롱폼 시퀀스 시간 기준) — SRT가 있으면 그것을 씀 |
| **S2 후보** | `criteria.md` 후킹 유형·구성 공식으로 후보 3~5개: 롱폼 구간(조각 목록)·예상 길이·후킹 유형·첫 문장·끝 문장·**상단 훅 문구 2~3안** |
| **S3 선택** | 사용자가 후보·훅 문구를 고름 (고친 문구는 그대로 씀) |
| **S4 제작** | 템플릿 숏폼 시퀀스 복제 → 롱폼 클립을 조각대로 복사해 이어 붙임 → 상단 훅 문구 → 하단 안내(단톡방 → 플레오라 전환) → 길이 맞추기 |
| **S5 보고** | 아래 형식으로 보고, 시퀀스 저장 |
| **S6 학습** | 사용자 검토(고친 컷·문구·길이) → 승인된 것만 `learnings.md`, 기준은 승인 후 `criteria.md` |

### 후보 보고 형식

```
  첫 문장: "…"  /  끝 문장: "…"
  뺀 것: 횟수 세기, 잡담 …
  상단 훅 문구: ① 1줄 / 2줄  ② …  ③ …
후보 2 …
```

- **롱폼 클립 복사 방법(시험 결과)**: 클립을 하나씩 `overwriteClip`으로 다시 놓으면 ① 영상이 "넣은 시간 + 원본 in 점"에 놓이고 ② 영상·오디오 연결 때문에 다른 트랙 클립이 지워지거나 덮임 → **롱폼을 복제해 카메라·오디오 트랙만 남긴 `<롱폼>_숏폼소스`를 중첩으로 넣는 방식**이 안정적(컷·카메라 전환·색보정·음량 그대로). 비율 95.83%(=1035/1080), 위치 (0.5, 958.5/1920). 오디오 트랙에 놓을 때는 시간 밀림 없음
- 복제한 숏폼 시퀀스에 **자막(캡션) 트랙이 남음** → 스크립트로 못 지움, 사용자가 삭제
- 롱폼 클립 복사 방법: 롱폼 시퀀스의 영상·오디오 트랙 클립을 같은 원본 in/out으로 숏폼 시퀀스에 다시 놓기 (또는 롱폼 시퀀스를 중첩해 상단 그래픽 트랙을 끈 복제본 사용) — **첫 작업에서 시험하고 사용자에게 확인**
- 롱폼 자막: 예시는 롱폼 자막이 영상 안에 들어간 클린본이었음 → 클립 복사 방식에서 자막을 어떻게 가져올지(캡션 트랙/자막 그래픽) 첫 작업 때 확인
