# 싱크 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값.

## 카메라 구분 (S2)
- 파일명 규칙은 쓰지 않는다 (프로젝트마다 다름). 확정
- 메타데이터(기종 → 해상도 → 코덱 → FPS) 순으로 묶는다. 초안
- **A캠 판단 기준: 각 클립의 프레임을 캡처해서 정면 구도와 넓은 샷이면 A캠으로 판단한다.** 확정 (사용자 지시, 2026-10-04)
  - 나머지 카메라는 B캠
  - 클립 길이·오디오 크기·메타데이터는 A캠 판단에 쓰지 않는다
- **운영 방식:** 초기에는 근거(캡처 화면 + 판단 이유)와 함께 사용자에게 묻고 확정받는다. 진행 중
  - 연속 3회 판단이 맞으면 사용자에게 자동 확정 전환을 **제안**한다 (동의해야 전환)
  - 현재: 판단 일치 **1회** (2026-10-04 둔근 운동법 C0020-002 = A캠, 프레임 캡처로 판단 → 사용자 확인)
- 오디오는 카메라 내장 오디오만 사용 (외부 녹음 없음). 확정

| 트랙 배치 | V1/A1 = 기준(A캠), V2/A2 = B캠, V3/A3 = C캠 … | 초안 |

## 카메라 라벨 (S10)
| 카메라 | 라벨 색 | 상태 |
|---|---|---|
| A캠 | **창포색 = colorIndex 1** (영상 기본값과 같지만, 다른 색으로 되어 있으면 1로 맞춘다) | 확정 |
| B캠 | **보라 = colorIndex 0** | 확정 |
- 모든 프로젝트에서 기본으로 적용한다 (사용자 지시, 2026-10-04)
- 라벨 번호 ↔ 한글 이름은 `agents/README.md`의 "Premiere 라벨 색 번호표"를 따른다. MCP 설명의 영어 이름(Purple 등)으로 짐작하지 않는다
- 촬영본 빈의 클립(프로젝트 아이템) 라벨을 바꾼다. MCP에는 타임라인 클립 라벨만 따로 바꾸는 도구가 없음
- ⚠️ 빈 라벨을 바꿔도 **이미 시퀀스에 올라간 클립에는 반영되지 않는다** (2026-10-04 확인).
  → 라벨은 반드시 **시퀀스에 배치(S5)하기 전에** 지정한다. 이미 배치했다면 클립을 빼고 같은 위치에 다시 올려야 한다
