# 플레이북 — 프리미어 템플릿을 애프터이펙트 템플릿으로 다시 만들기

**왜**: 프리미어로 만든 템플릿(`.prgraphic`)은 스크립트로 문구·폰트를 못 바꾼다 → 애프터이펙트 템플릿(`.aegraphic`)으로 다시 만들면 포인트 배치 때 문구·페이퍼로지 7Bold를 자동으로 넣을 수 있다.
**승인**: 2026-10-11, `05_실망 우울 좌절 모션자막` → `_AE` — 사용자 "좋아 프레임단위로 디테일 작업이 필요하겠어. 학습해줘." / 8개 전부 — "모두 원본과 유사하게 잘 작업됐어, 이런 프레임당 비교 후 디테일하게 작업한 부분 아주 좋아. 추후 유사한 작업 시에도 적용 가능하도록 학습해줘."
**적용 범위**: 템플릿 변환뿐 아니라 원본 모션·효과를 똑같이 재현하는 모든 비슷한 작업
**핵심**: 눈대중으로 맞추지 않는다. **원본과 새 것을 프리미어에서 프레임마다 뽑아 숫자로 비교**하고, 다를 때마다 원인을 찾아 고친다.

## 1. 원본 분석
1. 원본 `.mogrt`(zip)에서 `definition.json`, `thumb.png/mp4`, `project.prgraphic`(안에 gzip `.prproj` XML)를 `work/포인트/ae_templates/<이름>/`에 푼다. 원본 파일은 건드리지 않는다
2. `definition.json`: 길이(`duration`), 화면 크기, 문구 칸(`clientControls`)
3. XML: 클립에 걸린 효과(예: 시간 포스터화, 뒤틀기 변위)와 값, 키프레임(`<Keyframes>` — 틱 ÷ 254016000000 = 초). 글자 스타일·폰트는 base64(FlatBuffers) 안 — 폰트 이름 정도만 읽힘
4. 원본 폰트는 쓰지 않는다 → **페이퍼로지 7Bold** (포인트 기준 폰트)
   - 예외: 사용자 종편에서 가져온 정보형 4종(Tip!·노랑 2단·정보 바·해설 괄호)은 **원본 폰트 유지** (2026-10-12 사용자 "응 유지해줘"). `set_font.jsx`의 `KEEP_FONTS`가 건너뜀
   - 앞으로: 기본은 페이퍼로지로 가되, 사용자가 **템플릿 컨셉별로 폰트를 더 다양하게** 정할 계획 (2026-10-12) — 정해지면 그때 KEEP_FONTS·criteria에 반영

## 2. 프레임 비교 환경 (프리미어)
- 비교용 빈 시퀀스: 원본 시퀀스를 `duplicate_sequence(clearContents=true)`로 복제 (예: `포인트_AE비교_05_실망`). **캡션 트랙은 남으므로 자막이 없는 시간**(예: 12:25 = 745초)에 V1 원본, V2 새 것을 같은 시작·길이·문구로 놓는다
- 프레임 내보내기: `scripts/point/ae/export_frames.jsx` (QE `exportFramePNG`, 한 트랙만 켜고 프레임 번호로). **MCP `capture_frame`은 소수 초에서 엉뚱한 시각을 줄 수 있어 쓰지 않는다**
- 내보낸 PNG는 **알파가 따로**(RGBA, 곱하지 않음) → 투명도는 **알파 합**으로, 위치는 알파/밝기 경계로, 색은 RGB로 잰다

## 4. 애프터이펙트로 만들기
- 스크립트 `scripts/point/ae/make_<이름>.jsx` → `AfterFX.exe -r` (AE를 먼저 띄운 뒤 보냄, **한글 경로 스크립트는 ASCII 경로로 복사**해서 실행). 결과 `result.txt`
- 문구 칸: 텍스트 레이어 `Source Text`를 `addToMotionGraphicsTemplateAs(comp, "자막 텍스트")`
- 내보내기: `exportAsMotionGraphicsTemplate(true, <폴더>)` — **경로를 폴더로 씀**(`제목 없음.mogrt`) → `scripts/point/ae/finish_mogrt.py <폴더> "<원본이름>_AE" "<표시 이름>"`가 "내 템플릿"으로 옮기고 폰트·크기 변경 허용으로 고침 (`_AE` 이름만 허용 — 원본 덮어쓰기 방지)
- AE 확인 프레임: `comp.saveFrameToPng` (**한 스크립트에서 여러 번 부르면 첫 장만 저장될 수 있어 별도 스크립트로**)

## 5. 알게 된 함정 (05_실망)
- **Posterize Time 효과**는 위치·불투명도까지 끊는다 → 끊기는 건 일렁임 "진행"에만 식으로: `var f=Math.max(0,Math.floor((timeToFrames(time)-1)/10)*10+1); framesToTime(f)*<초당 진행>` (원본처럼 1·11·21…프레임에 바뀜)
- 일렁임 세기는 **원본 값 그대로**(뒤틀기 변위 양 10). 눈대중으로 키우면 두 배로 출렁임
- **텍스트 레이어에 Ramp를 직접 걸면 좌표가 안 맞아 한 색** → 화면 크기 단색 판에 Ramp + 글자 레이어로 **알파 매트**(`setTrackMatte(L, TrackMatteType.ALPHA)`), 끝점은 `L.toComp(sourceRectAtTime)`로
- 테두리·그림자는 아래 레이어에 따로: Source Text 식 `s.style.setText(s.value).setFillColor(…).setApplyStroke(true)…` → 문구·폰트가 위 레이어를 따라감
- 레이어가 여러 개 겹치면 같은 불투명도라도 원본보다 진해짐 → **겹친 결과 알파가 원본과 같도록 프레임별로 역산**한 값 넣기
- 움직임은 원본 측정값을 **프레임마다 키**로 넣는다 (곡선 추정보다 정확)
- 프리미어 클립 이름이 "제목 없음"으로 나옴 (사용에는 지장 없음)

## 6. 사용자 확인
- 시험 시퀀스(원본 시퀀스 복제, 예: `_포인트_AE시험`)의 실제 구간에 V6 원본 / V7 새 것을 놓고 사용자가 재생해 확인
- 사용자가 지적한 항목은 다시 2~3으로 프레임 측정 → 원인 → 수정
- **프리미어 시간 포스터화의 바뀌는 프레임 = floor(k × 30 ÷ fps) + 1** (29.97이 아니라 30 기준). 4fps → 8·16·23·31·38·46·53, 3fps → 1·11·21·31… AE에서는 진행 식으로 같은 프레임에 바뀌게 한다 (`make_bom.jsx` turb)

## 7. 추가로 알게 된 것 (2026-10-11, 7개 제작 중)
- 흔들림 템플릿(외부 플러그인 "Wiggle"): 키가 없어 설정값만으로는 모름 → 프레임에서 **덩어리(단어/글자)별 무게중심**을 재서 표준편차·앞 프레임 상관으로 맞춤 (`measure_words.py`, `measure_chars2.py`). AE 쪽은 텍스트 애니메이터 + Wiggly 선택기(기준 단어=3 / 글자 공백 제외=2 / 글자=1), 크기 ≈ 표준편차 ÷ 0.4, 빠르기는 상관이 원본과 같아질 때까지
- 부모(널)를 붙일 때 AE가 부모 크기를 상쇄해 자식 크기를 바꿈 → 붙인 뒤 자식 크기를 100으로 되돌림
- 단어 일부 색(봄03·04 뒤 단어 분홍, 봄06 앞 단어 주황): 채움 색 애니메이터 + 범위 선택기(단어 기준, 시작·끝 %)
- 식 안에 색을 넣을 때는 소수 자릿수를 줄인 문자열로 (`toFixed(4)`) — 긴 소수는 "0으로 나눔" 오류가 남
- **AE 대화상자가 뜨면 이후 스크립트가 모두 멈춤**: 저장 창(시작에 `app.project.close(DO_NOT_SAVE_CHANGES)`), 파일 못 찾음 창(경로 역슬래시는 반드시 `\`, `app.open` 전에 `exists` 확인, `beginSuppressDialogs`). 스크립트가 안 먹으면 AE 창 목록을 보고 사용자에게 닫아 달라고 요청
- PowerShell 5.1: 한글이 들어간 `.ps1`은 **UTF-8 BOM**으로 저장
- 비교 도구는 **해당 위치 클립만** 바꾸고, 끈 클립은 끝나면 되돌림 (`place_compare.jsx`, `export_frames.jsx`) — 트랙을 통째로 비웠다가 사용자 확인용 배치를 지운 적 있음
- 한 번에 많이 내보내면 MCP 45초 시간 초과 → 템플릿별로 나눠서
- 텍스트 애니메이터 식 선택기(Expressible Selector) 두 개로 높이·기울기를 묶으면 따로 놂 → 원인은 아래 random() (봄03 회전 2026-10-11 승인: "부드럽게 수정 잘 됐어")
- **AE `random()`은 `seedRandom`이 같아도 속성(레이어·속성)마다 다른 값** → 두 속성을 같은 흔들림으로 묶으려면 위상을 글자 번호 등으로 계산 (`(textIndex*137.13)%1000`)
- 흔들림에 따라 붙는 움직임(봄03 튈 때 기울기)은 앞뒤 7개 시점(3프레임 간격) 평균 + `ease(up,0.2,0.55,0,1)`로 천천히 → **프레임당 변화 최대 약 2°, 3° 넘는 변화 0**이면 부드러움 (승인), 막대 글자 "ㅣ" 시험 문구로 기울기 측정
- ExtendScript에서 File·Error 개체를 문자열과 `+`로 이으면 오류 창 → `String(x)`. 진단 스크립트는 단계마다 파일에 바로 기록(열고-쓰고-닫기)하고 오류는 `err.message`만
- AE 환경 설정 "스크립트에서 파일 쓰기 및 네트워크 액세스 허용"이 꺼지면 결과 파일 쓰는 줄에서 모두 멈춤 (강제 종료 뒤 확인)

## 9. AE 자동 실행 — 멈춤·실패 재발 방지 (2026-10-12, 반드시 지킬 것)
원인: 이날 AE 스크립트가 세 번 멈추거나 실패함. 사용자 "왜 계속 작업이 안 되는지 원인 파악 후 알려줘."
1. **프리미어가 띄운 창 없는 AE가 따로 있다**: AE로 만든 템플릿을 프리미어에서 재생·렌더하면 `dynamiclinkmanager.exe`가 `AfterFX.exe -m`(창 없음)을 띄움. 이것을 "켜진 AE"로 착각하면 창 있는 AE 없이 `-r`을 보내 스크립트가 엉뚱한 곳으로 가거나(내보내기 false), 창 있는 AE가 하나 더 떠서 두 개가 같이 돌다 내보내기에서 멈춤
   → **항상 `scripts/point/ae/run_ae.ps1`로만 보낸다.** 창 있는 AE만 인정, 없으면 띄우고 창이 뜬 뒤 15초 기다렸다 보냄, 창 있는 AE가 2개면 보내지 않고 멈춤. 사용: `run_ae.ps1 <jsx> <result.txt> "<끝 표시>" <최대 초>`
   → 창 없는 AE(`-m`)는 사용자 허락 없이 끄지 않는다 (프리미어가 씀). 강제 종료 뒤 "AE가 저절로 다시 켜짐"은 대부분 이것
2. **저장 안 된 프로젝트에선 `exportAsMotionGraphicsTemplate`가 false** → `app.newProject()` 바로 뒤에 `app.project.save(...)`
3. **단계마다 시작 기록**: 크기·그림자·움직임·항목 등록·내보내기 시작을 `w()`로 바로 파일에 씀 → 멈추면 마지막 줄 다음 단계가 원인. 끝 표시(예: `Bracket export`)가 나올 때까지 기다리고, 시간 초과면 AE 응답 여부와 함께 보고
4. 멈춘 것 같으면: 결과 파일 마지막 시각 + AE CPU 변화(5초) + `Get-CimInstance Win32_Process`로 명령줄·부모 확인 → 사용자에게 원인과 함께 알리고, 닫아도 되는지 묻고 닫기 (열려 있는 건 내 임시 프로젝트뿐인지 확인)
5. AE 작업 중에는 프리미어에서 AE 템플릿 렌더·배치를 같이 하지 않는다 — "AE 제작 → 내보내기 끝 → 프리미어 비교" 순서로
