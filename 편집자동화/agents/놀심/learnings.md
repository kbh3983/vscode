# 놀심 — 잘된 결과 (따라 할 것)

사용자가 **명시적으로 승인한** 결과와 그 방법만 적는다. 형식:
```
## 제목 (날짜, 영상)
- 상황:
- 한 방법 / 사용한 값:
- 사용자 피드백 (원문):
- 다음에 적용할 점:
```
