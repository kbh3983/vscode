# 놀심 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 레퍼런스 측정값이고 아직 사용자가 승인하지 않은 값이다. 근거는 `work/놀심/분석/통합분석.md`(절 번호)이다.

> **적용 범위:** 표시 없는 줄 = 놀심 공통, `[인터뷰]` = Q 카드 + PD 목소리 형식(r1·r2·r3·r5·r6 — 상담사 출연편, 화면엔 출연자 혼자), `[1인]` = 진행자 혼자 말하는 형식(r4).
