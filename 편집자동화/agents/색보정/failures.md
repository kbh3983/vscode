# 색보정 — 잘 안된 결과 (하지 말 것)

사용자가 불만족한 결과. **같은 실수를 피할 때만** 참고한다. 좋은 방법의 근거로 쓰지 않는다.

형식:
```
## [단계] 제목 (날짜, 프로젝트명)
- 상황:
- 한 방법 / 사용한 값:
- 무엇이 문제였나 (사용자 피드백 원문):
- 하지 말 것:
```

---

## [W4] 피부 밝기를 기준으로 어두운 영역을 50까지 올려 넓은 화면이 너무 밝아짐 (2026-10-09, 옆구리살_종편_모노_색보정_60초)
- 상황: V1(B캠, 옆에서 찍음)을 V2(C캠, 정면)에 맞출 때 세 장면(10.5·27·51초) 평균의 "피부 밝기"(V1 130 / V2 152)를 맞추려고 조명 → 어두운 영역 +50 (노출 +0.1, 검정 −3), 16개 클립 모두 같은 값
- 무엇이 문제였나 (사용자 피드백 원문): "V1 에 8:17초 구간부 터 있는 클립의 보정 결과가 너무 밝아. 확인ㅇ해보니까 "조명"에서 어두운 영역을 50까지 올린거같아. 어떤 기준으로 50까지 올린거야?"
- 원인: ① 두 카메라의 피부는 **빛 받는 방향이 달라** 같은 기준이 아님 ② 넓은 화면(8~12초)에서는 바닥·매트가 "피부"·"벽"에 섞임 ③ 검정을 다른 두 장면 기준으로만 맞춰, 그 클립은 검정이 29→42~50으로 떠도 평균에 묻힘
- 하지 말 것: 피부(또는 촬영 각도에 따라 빛이 달라지는 부분)로 **밝기**를 맞추지 않는다. 장면 구성이 다른 클립에 한 값을 일괄로 넣지 않는다. 여러 장면 평균으로 판단하지 말고 클립마다 확인한다

## [W4] V1 채도 115를 근거 없이 계속 넣어 살색이 튐 (2026-10-09, 옆구리살_종편_모노_컷전환_색보정)
- 상황: 60초 1차(거절)에서 어두운 영역을 올려 묽어진 피부를 메우려 채도 125 → 30초 재작업 때 어두운 영역은 0으로 되돌렸는데 채도 115는 다시 재지 않고 남김 → V1 기본값으로 굳어 컷전환 색보정 21구간에도 그대로 들어감
- 무엇이 문제였나 (사용자 피드백 원문): "응 채도를 원래 100으로 돌려줘, 지금은 V2보다 채도가 너무 높아서 살색이 튀네. 수정해줘."
- 원인: 보정 전 V1 피부는 V2보다 어둡기만 하고 묽지 않았음(밝기 대비 색은 오히려 진함). 채도를 올릴 이유가 사라진 뒤에도 값을 확인하지 않음
- 하지 말 것: 다른 단계·다른 방식에서 나온 값을 근거 확인 없이 기본값으로 가져오지 않는다. 채도는 100(원래 값)에서 시작하고, 바꾼다면 같은 순간 V2와 피부색 진하기를 재서 근거가 있을 때만

## [W4] 원본이 분홍빛인 B캠 조각·밝기 차이 경계가 남음 — 사용자가 직접 보정 (2026-10-10, 목교정기_종편_모노_색보정 0:12–0:15, 0:37)
- 상황: 0:12–0:15 B캠 조각은 원본 자체가 분홍빛(편집자도 색조 −15로 따로 잡음). 0:37은 V2→V1 경계에서 밝기 차이(기준 V2가 같은 순간 더 가까이 잡은 화면)
- 한 방법 / 사용한 값: 다른 조각과 같이 3회 반복, 색조 반 걸음 → 0:12 조각 G−중간 −3 남음, 경계 벽 R−B −6. 0:37은 V2 기준 밝기 185에 맞춰 V1 밝기를 내림
- 무엇이 문제였나 (사용자 피드백 원문): "0:12–0:15 B캠 조각: 차이가 있긴한데, 내가 직접보정할게. 마크는 놔둬줘. 0:37: 차이가 나는데, 이것도 내가직접할게."
- 하지 말 것: 원본 색이 크게 다른 조각(처음 측정 벽 색 차이가 ±5 넘음)을 다른 조각과 같은 3회로 끝내지 않는다 — 따로 더 반복하거나 남은 차이를 숫자로 알린다. 기준 V2가 화면 구성이 다른 순간(가까운 화면 등)이면 밝기를 그 값에 그대로 맞추지 말고 알린다
