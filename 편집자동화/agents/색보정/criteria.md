# 색보정 기준값

`(초안)` = 아직 실제 결과로 검증되지 않은 값.

| 항목 | 값 | 상태 |
|---|---|---|

| 다른 트랙 | 흰색 균형 후 색상·조명·곡선으로 V2 결과에 맞춤 | 확정 (사용자 지정) |

## 작업 규칙
| 항목 | 값 | 상태 |
|---|---|---|
| **작업 시점** | **컷편집이 끝난 시퀀스에서** 실행 | 확정 (사용자 지정, 2026-10-09) |
| **B캠 밝기 상한** | B캠은 **A캠보다 밝게 하지 않는다** — 노출을 올린 뒤 밝은 쪽(95%)이 같은 순간 A캠 95%를 넘지 않게. 맞추는 기준은 **바닥·벽 같은 공통 물체**: B캠 "흰 면"이 A캠 벽보다 15 이상 어두우면 바닥(클로즈업)으로 보고 노출을 올리지 않음 (`batch.py` FLOOR_GAP·p95 상한) | 확정 (2026-10-13 목교정기 최종본 회고 후 사용자: "a캠보다 밝지 않게 바닥, 벽 기준으로 맞추기 좋고") — 목교정기 1:28~2:26 클로즈업에서 제 노출 0.7~0.8 → 사용자 0.4 |
| **같은 장면 한 값** | 같은 B캠 파일에서 원본 시간이 5초 안으로 이어지고 **맞춘 값 차이가 노출 0.2·온도 1.5 이하**인 클립들 = 같은 장면 → 온도·색조·검정은 **중간값 하나**, 노출은 **중간값(제 값이 더 어두우면 제 값)** (`batch.py group`, SCENE_GAP 5초·SCENE_EXPO 0.2·SCENE_TEMP 1.5 — 2026-10-13 틀어진골반 승인 "잘 작업됐어. 학습해줘.") | 확정 (2026-10-13 목교정기 최종본 회고 후 사용자: "같은 장면 b캠은 한 값으로 묶는 것 좋아") — 사용자 최종 B캠 기본값 예: 온도 −14.3 / 색조 1.7 / 노출 0.4 / 검정 −8 |
| **보정 대상** | **A캠(V2)·B캠(V1) 전체 카메라 클립** — 꺼진 V2, 가려진 V1 포함. V2는 한 값, V1은 클립마다 같은 순간의 V2와 비교한 값 (사용자가 컷전환을 다시 확인해 쓰거나 안 쓰는 경우가 많음). **이미 작업이 끝난 영상은 다시 보정하지 않는다** — 새로 하는 작업부터 적용 (2026-10-13 사용자: "이건 작업이 끝난 영상이라 전체 보정은 필요없어", 옆구리살) | 확정 (사용자 지정, 2026-10-12 — 2026-10-09 "보이는 맨 위 레이어만"에서 변경) |
| 첫 작업 범위 | 처음 60초만 별도 시퀀스로 | 확정 (사용자 지정, 2026-10-09) |
| 원본 시퀀스 | 아무것도 건드리지 않음 | 확정 (사용자 지정) |
| 마커 | V1 미세조정 구간 표시 | 확정 (사용자 지정) |

## 측정
| 항목 | 값 | 상태 |
|---|---|---|
| 배경 판정 | 밝고(밝기 > 130) 색이 옅은(최대−최소 < 45) 픽셀 = 흰 배경 | 초안 |
| 무채색 판정 | 배경 중앙값 R−B, G−(R+B)/2 가 ±1 이내 | 초안 |
| **밝기 맞추기 기준** | **흰 배경 밝기 + 검정(어두운 5%)만.** 피부는 색(R−G, G−B)에만 쓰고 밝기에는 쓰지 않음 | 확정 (사용자 동의, 2026-10-09) |
| **비교 단위** | **V1 클립마다** 같은 순간의 V2(그 시각 V2 클립을 잠깐 켜서 렌더)와 비교, 클립별 값 | 확정 (사용자 동의, 2026-10-09) |
| 어두운 영역 | 0에서 시작 (올리면 검정이 뜸) | 초안 |
| **편집자 기존 Lumetri** | 작업 전에 덮어쓸지 사용자에게 물음 | 확정 (승인, 2026-10-10 목교정기) |
| **자료화면이 덮는 조각** | 측정하지 않고 처음 값, 마커에 표시 | 확정 (승인, 2026-10-10 목교정기) |
| **검정 예외** | V1·V2 어두운 5% 차이 **12 초과** 조각은 검정 처음 값 (화면 구성 차이) | 확정 (승인, 2026-10-10 자세교정) |
| **채도 (다른 캠)** | **100 (원래 값).** 115로 올렸더니 살색이 튐 | 확정 (사용자 지정, 2026-10-09) |
| 측정용 렌더 | In/Out 1프레임 + `PNG Sequence (Match Source).epr` (export_frame 쓰지 않음) | 확정 (도구 문제) |
