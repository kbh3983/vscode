## 1. 사용자 설명 (원문)

### 현재 상황
- 영상은 V1, V2, V3 등 있을 수 있어
- 여기서 **V2를 먼저 화이트밸런스를 모두 적용**해줘. V2가 기준이 되는 이유는 **V2가 메인캠**이기 때문이야
- 화이트밸런스를 적용한다는 의미는 **Lumetri 색상 탭에 있는 기본 교정의 "흰색 균형" 도구를 이용해서 배경색을 화이트로 맞추는 작업**이야
- V2가 화이트밸런스가 적용된 다음에는, **다른 영상들을 V2에 맞춰야** 해

### 문제 상황
- 다른 영상의 경우 "흰색 균형"만 적용하면 안 되는 문제가 있어
- V1도 마찬가지로 "흰색 균형" 도구로 화이트밸런스를 맞춘다고 하자. 그러면 **각 영상의 카메라가 다르기 때문에, 화이트밸런스를 맞춰도 그 결과가 약간씩 달라**
- 그래서 V2의 화이트밸런스에 맞게 V2를 제외한 다른 영상들은 Lumetri 색상 도구에서 **"색상"과 "조명" 그리고 "곡선"** 도구를 이용해서 일일이 조정해줘야 해
- V3나 다른 영상에 대해서도 마찬가지야. 화이트밸런스를 적용하고, Lumetri 색상 도구를 이용해서 **V2에 화이트밸런스를 적용한 결과와 동일한 화이트밸런스가 되도록 미세조정**을 해야 해

### 중요한 점
- 시퀀스의 **처음 60초만 먼저** 작업해서 **별도의 시퀀스**로 만들어줘
- **현재 있는 시퀀스는 아무것도 건드리면 안 돼**
- **V1에서 미세조정이 적용된 부분은 마커로 표시**해줘 (확인용)

## 2. 절차 (승인된 방법)

### 2-1. 준비
0. **컷편집이 끝난 시퀀스인지 확인**한다. 보정은 화면에 보이는 맨 위 레이어(클립)에만 넣고, 위 트랙에 가려진 클립은 건드리지 않는다 (사용자 지정, 2026-10-09)
1. 대상 시퀀스를 **이름으로** 찾는다 (열려 있는 시퀀스라고 가정하지 않음)
2. 원본 복제 → `<시퀀스>_색보정_<N>초` → 앞부분만 남기고 razor·삭제 (QE `razor`, 드롭프레임 타임코드). 잠긴 트랙은 복제본에서만 잠깐 풀었다가 다시 잠금
3. 비디오 트랙별 카메라와, V2가 꺼져 V1(등)이 보이는 구간을 정리

### 2-2. 측정 방법 (모든 단계 공통)
- In/Out을 1프레임으로 잡고 MCP `export_sequence` + `PNG Sequence (Match Source).epr` → 결과 이름 끝에 `0`이 붙음
- **`export_frame`은 쓰지 않는다** (일부 시각에서 영상 앞부분 화면을 냄). 의심되면 `scripts/color/check_frame.py`로 원본과 일치 확인
- `scripts/color/img.py`: 흰 배경 = 밝기 > 130 · 최대−최소 < 45 픽셀의 중앙값, 검정 = 어두운 5%, 피부 = R>G>B 색 조건

### 2-3. V2 화이트밸런스 (W3)
1. V2 모든 클립에 Lumetri 색상 추가 (`scripts/color/set_lumetri.jsx`, QE `addVideoEffect`)
2. 흰 배경 R−B → 0이 되게 온도(14), G−(R+B)/2 → 0이 되게 색조(15). 렌더해 재면서 맞춘다 (스포이트 13번은 색만 들어가고 계산 안 됨)
3. V2가 보이는 구간 여러 곳에서 무채색(±1) 확인

### 2-4. 다른 트랙 맞추기 (W4) — 클립마다
1. 처음 값: 같은 카메라의 흰색 균형(온도·색조)만, 채도 115, 노출·어두운 영역·검정 0
2. 보이는 클립마다 가운데 시각에서: V2 클립 잠깐 켜기 → V2 기준 렌더 → 끄기 → 대상 트랙 렌더
3. `scripts/color/clipmatch.py <접두어> <현재값.json>` → 흰 배경 색(온도·색조), 흰 배경 밝기(노출), 검정(검정) 차이와 다음 값
4. 클립별로 값 넣고 다시 렌더 → 벽 무채색 ±1, 벽 밝기 ±3, 검정 ±3 안에 들 때까지 (보통 3회)
- **피부로 밝기를 맞추지 않는다**, **어두운 영역은 0** (failures.md)
- 곡선은 스크립트로 못 넣음 → 색상·조명으로 맞춘다

### 2-5. 마무리 (W6)
