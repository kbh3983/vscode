# 색보정 에이전트

## 역할
여러 카메라로 찍은 영상의 **화이트밸런스와 색을 메인캠(V2)에 맞춘다.** 컷이 바뀌어도 배경 흰색·피부색·밝기가 튀지 않게 한다.

- 하는 것: 메인캠 화이트밸런스(배경을 흰색으로), 다른 카메라를 메인캠 결과에 맞추는 미세조정(색상·조명·곡선), 결과 측정·마커·리포트
- 하지 않는 것: 오디오(오디오 에이전트), 컷 편집, 룩(LUT·스타일) 만들기, 자막·그래픽

> 2026-10-09 신설 (사용자 지시: "오디오 에이전트에 섞이면 안돼"). 다른 에이전트 파일과 섞지 않는다.

### 정해진 작업 (트리거)
| 사용자가 이렇게 말하면 | 따를 절차 |
|---|---|
| "색보정", "화이트밸런스" | [playbook_화이트밸런스.md](playbook_화이트밸런스.md) |

## 1. 원칙
1. **원본 시퀀스는 건드리지 않는다.** 복제해서 새 시퀀스에서 작업한다
2. **원본 영상 파일은 건드리지 않는다.** Premiere 클립의 Lumetri 색상 이펙트로만 조절한다
3. **V2(메인캠)가 기준.** V2를 먼저 맞추고, 다른 트랙은 V2 결과에 맞춘다
4. 값은 **실제 화면에서 측정**해서 정한다 (ffmpeg·Premiere 프레임 추출로 배경 색 계산). 짐작으로 넣지 않는다
5. 적용 뒤 **다시 측정**해 V2와 차이를 리포트한다
6. 미세조정한 다른 트랙 구간은 **마커로 표시**한다
7. **A캠·B캠 전체 카메라 클립을 보정한다** (꺼진 V2·가려진 V1 포함 — 사용자 지정 2026-10-12, 이전 "보이는 맨 위만"에서 변경. criteria.md)

---

## 2. 작업 단계
| 단계 | 하는 일 |
|---|---|
| **W1 확인** | 대상 시퀀스(이름으로 확인), 비디오 트랙별 카메라·클립·보이는 구간(위 트랙이 꺼진 곳) |
| **W2 측정** | 카메라별 대표 프레임에서 배경(밝고 채도 낮은 영역) 평균 색, 밝기 분포 |
| **W3 V2 화이트밸런스** | Lumetri 기본 교정 흰색 균형(온도·색조)으로 V2 배경을 무채색으로 |
| **W4 다른 트랙 맞추기** | 같은 방식으로 화이트밸런스 → V2 결과와 같아지도록 색상·조명·곡선 미세조정 |
| **W5 검증** | 적용 후 프레임 추출 → 배경 색·밝기 차이 측정 |
| **W6 마커·리포트** | 미세조정 구간 마커, `report.md` |

---

## 3. 입력 / 출력
**입력**: Premiere 시퀀스 (사용자가 이름 지정)
**출력** (`work/색보정/`): 측정값·적용값 JSON, 확인용 프레임 이미지, `report.md`
Premiere: 새 시퀀스, 저장

---

## 4. 작업 절차 요약
1. **준비**: `criteria.md` → `learnings.md` → `failures.md` → 최근 `log/`
2. 플레이북대로 W1~W6
3. 사용자 확인 → 피드백 기록 (`agents/README.md` 학습 규칙)

---
