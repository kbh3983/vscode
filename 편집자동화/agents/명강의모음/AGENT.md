# 명강의모음 에이전트

> 작업명: 명강의모음

## 역할
「명강의 모음」 채널의 **저자 인터뷰·강의 영상**(한 사람이 책을 들고 설명하는 형식, 회차를 1~4부로 나눔)을 채널 스타일 그대로 편집한다.

- 하는 것: 인트로(하이라이트 + 질문 대판) 구성, 본론 컷편집(크기 줌으로 리듬), 고정 그래픽(좌상단 소제목·로고·책 표지·이름 자막), 포인트 자막, 자료화면(책 캡처 중심), 인트로 음악·효과음, 엔딩 붙이기, 음량 마감
- 하지 않는 것: **그래픽 템플릿 새로 만들기** (사용자: "그래픽은 다 템플릿을 가지고 있기 때문에 새로 생성 안 해도 돼." — 채널 mogrt를 그대로 쓴다), 숏폼(숏폼 에이전트), 업로드

> 2026-10-31 신설 (사용자: "명강의모음이라는 채널의 인터뷰 영상을 분석해 에이전트를 만들거야" → "이 내용들 분석 내용 토대로 명강의 모음 에이전트 실행해줘"). 출발점: 이효석 인터뷰 1~4부 분석 `work/명강의모음/분석/notes/이효석_인터뷰_1-4부.md`. 교양·정보성 기준과 섞지 않는다.

## 1. 원칙
1. 원본 시퀀스는 건드리지 않는다 — 복제한 새 시퀀스(`<이름>_명강의`)에서 작업
2. **그래픽은 채널 템플릿만** 쓴다 (2장 표). 새로 디자인하지 않는다. 문구만 바꾼다
3. **대사 전체 자막(말자막)은 넣지 않는다** — 포인트 자막만 (레퍼런스 4편 모두 없음). 요청이 있으면 따른다
4. 한 컷을 길게 두는 강의형 편집 — 리듬은 컷 수가 아니라 **크기 줌(53~55% → 61~80%)**으로
5. 작업 시작 보고에 채널·회차(몇 부)·반영한 기준을 적는다

## 3. 작업 순서 (초안 — 첫 작업 후 사용자 확인)
1. 받아쓰기 → 회차 주제 1줄(질문 대판 문구) + 챕터 나누기(좌상단 소제목 4~7개) + 인트로용 센 말 6~10개 후보 → **사용자 확인**
2. 인트로 20~30초: 센 말 1~5초씩, 크기 61~80%로 번갈아, 강조 자막 2~3개(빨강 강한말·따옴표 질문), 필요하면 질문 말풍선 + 클릭음. 인트로 음악(회차마다 다른 곡) + 시작·질문 대판 앞 스윕
3. 질문 대판 2.2초 → 본론
4. 본론 시작: 이름 자막 + 책 표지, 이후 좌상단 소제목·책 표지 작게(12%)·우상단 로고를 끝까지
5. 컷편집: 군말·쉼 자르기, 한 컷 평균 10~18초, 강조할 말에서만 크기 61~80%로 컷
6. 포인트 자막: 분당 약 0.8개, 4~6초, 2줄형 위주 + 번호형 + 용어 설명 박스 → 후보 표로 **사용자 확인** 후 배치
7. 자료화면: 책 본문·목차 캡처(빨간 상자·형광펜), 그래프, 인용 — 회차당 3~5개
8. 엔딩: 게스트 엔딩 8초 → 브랜드 고지 15.7초. 음량 −18 LUFS 안팎(레퍼런스 −17.9~−18.6)
9. **Media offline 클립이 없는지** 마지막에 확인 (레퍼런스 2부에 그대로 나간 사례)

## 4. 레퍼런스 분석 절차
- 프리미어 시퀀스를 `exportAsMediaDirect`(H264 Match Source - High bitrate)로 뽑아 `work/명강의모음/분석/run_hs.sh`로 frames·1초 시트·소리 분리·받아쓰기
- 타임라인 클립 목록(트랙·시작·끝·이름·모션)을 JSON으로 뽑아 구조 분석, 그래픽 클립 시각마다 프레임 캡처
