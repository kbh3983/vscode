## 채널 mogrt 5종 AE판 — 스크립트로 문구 넣기 (2026-10-31, 이효석 5부 준비)
- 상황: 채널 템플릿 10개가 모두 프리미어에서 만든 템플릿(.prgraphic)이라 스크립트로 문구를 바꾸면 글자가 사라짐 → 자주 쓰는 5개를 AE판으로 다시 만듦
- 한 방법 / 사용한 값:
  - agents/포인트/playbook_AE변환.md 방식 + scripts/myeong/ae/ (make_point.jsx·make_box.jsx를 설정 JSON으로, compare·fit_point·optimize·fit_blur로 프레임 비교 맞춤). 설정·분석 work/명강의모음/ae_templates/<이름>/cfg_*.json, 분석_메모.md
  - 비교 기준은 원본 mogrt 사본에서 폰트 이름만 이사만루로 바꿔 프리미어에서 뽑은 프레임 (공고딕 → 이사만루, 사용자 지시)
  - 설치 이름 `명강의 모음_<이름>_AE` — 포인트자막(고딕)·2(명조)·3(한줄)·중앙 포인트 자막·설명,다용도박스. 싱크로 94.5·95.7·96.4·81.3·90.0%
  - 문구 표시: 포인트 3종 `{노랑}` `[하늘]`, 중앙 `{굵게}` — Source Text 식이 괄호를 지우고 그 글자만 색·폰트
  - 중앙 mogrt는 설치 후 definition.json fontEditValue를 esamanruOTFLight로 고쳐야 함 (AE가 Medium으로 적음)
- 사용자 피드백 (원문): "좋아 이상없어, 이걸로 쓰면 되겠다."
- 다음에 적용할 점: 포인트 자막·중앙 자막·설명 박스는 이 AE판으로 자동 배치한다. 단어 강조는 표시 괄호로. 다른 채널 템플릿도 같은 도구로 AE판을 만들 수 있음 (폰트 이름 바꾼 비교 기준 → 설정 JSON → 프레임 비교)
