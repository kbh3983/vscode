# 에이전트 공통 구조

각 에이전트는 `agents/<이름>/` 폴더 하나를 가진다.

```
agents/<이름>/
├── AGENT.md       역할, 담당 태스크, 작업 절차, 입출력 (에이전트의 "직무 기술서")
├── playbook.md    승인된 작업을 그대로 재현하는 실행 절차서 (도구 호출·명령·값). 승인된 결과가 생기면 만든다
├── criteria.md    현재 적용 중인 기준값·규칙 (승인된 것만 반영)
├── learnings.md   사용자가 승인한 좋은 결과와 그 방법
├── failures.md    사용자가 불만족한 결과 ("하지 말 것" 목록)
└── log/
    ├── _template.md
    └── YYYY-MM-DD.md   날짜별 작업 기록
```

## 작업 시작 전 (모든 에이전트 공통)
1. `AGENT.md` → `playbook.md`(있으면) → `criteria.md` → `learnings.md` → `failures.md` 순서로 읽는다.
2. `log/`에서 가장 최근 기록 1~2개를 읽어 이어지는 맥락을 파악한다.

## 영상 종류 (적용 범위) — 2026-10-14
- 에이전트는 **작업별로 하나씩** 두고, 영상 종류(운동·강연 등)는 기준 표 안에서 구분한다 (사용자 결정).
- `criteria.md`에서 **표시 없는 줄 = 공통**. `[운동]`(운동법 영상 — 채널 상관없이) / `[최박사]`(최박사 채널의 촬영 환경·화면 구성·템플릿) / `[설명]`(설명·상담형) / `[강연]` 표시가 있는 줄은 그 경우에만.
- 작업 시작 보고에 **채널과 영상 종류**를 적는다 (예: "채널: 최박사 / 종류: 운동 → 공통 + [운동] + [최박사]", "종류: 강연 → 공통 + [강연]"). 새 채널이면 [채널] 줄은 쓰지 않고 그 채널 기준을 새로 묻는다. 그 종류 기준이 없는 항목은 공통으로 하고 애매하면 묻는다.
- 학습할 때 그 피드백이 **영상 종류 때문인지, 채널 때문인지** 적용 범위를 함께 적는다 (애매하면 묻는다). 강연에서 승인된 것이 운동 기준을 바꾸지 않게.
- 강연에만 있는 작업(예: 슬라이드 넣기, 질의응답 정리)이 생기면 그때 새 에이전트를 만든다.
- 분류 근거: `docs/영상종류_분류안.md`

## 학습 규칙
| 사용자 반응 | 기록 위치 | 다음 작업에 반영 |
|---|---|---|
| 명시적 승인 ("좋아", "이걸로 가자") | `log/` + `learnings.md` (+ 재현할 절차는 `playbook.md`) | ✅ 따라 한다 |
| 불만족·수정 요청 | `log/` + `failures.md` | ⛔ 반복하지 않는다 |
| 반응 없음 / 애매함 | `log/`에만 "보류"로 기록 | ❌ 반영하지 않는다. 다음에 사용자에게 확인한다 |

- `criteria.md`의 기준값은 **사용자가 승인한 경우에만** 바꾼다. 바꿀 때 이전 값과 변경 이유를 같이 남긴다.
- 같은 피드백이 2번 이상 반복되면 `criteria.md` 규칙으로 올릴 것을 사용자에게 제안한다 (자동으로 올리지 않는다).
- `failures.md`는 "하지 말 것"을 확인할 때만 쓴다. 좋은 방법의 근거로 쓰지 않는다.

## 하루 작업 종료 시
- `log/YYYY-MM-DD.md` 작성 (템플릿: `log/_template.md`)
- 프로젝트 전체 진행은 `docs/progress.md`에도 한 줄 남긴다.

## Premiere 스크립트로 안 되는 것 (2026-10-14 강연 작업에서 확인)
- **타임라인 클립 라벨 색 바꾸기** — TrackItem·QE 모두 기능 없음 → 클립 이름 표시(`[교육n]`) + 해당 클립 선택 상태로 두고 사용자가 편집 → 레이블 → 색
- **자막(캡션) 클립 지우기·고치기·읽기, 자막 트랙 지우기** — 불가 → 필요한 줄만 남긴 SRT로 `createCaptionTrack` 새 트랙 + 사용자가 기존 트랙 삭제
- **클립 많은 시퀀스(약 3,000개)에서 `setSelected` 반복** — 매우 느려 45초 시간 초과 후 수 분 걸림. `remove(false,false)`는 약 30개/초 → 600개씩 나눠서
- 되는 것: `razor_all_tracks`(시간 정확, 1프레임 이내), 클립 이름 바꾸기, 시퀀스 마커(구간 길이·색)
