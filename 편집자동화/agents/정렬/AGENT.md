# 정렬 에이전트

> 작업명: 정렬 (가이드라인)

## 역할
이미 시퀀스에 놓인 **포인트 자막**의 크기·위치를 사용자가 정한 가이드선(A/B/C/X/Y)에 맞춘다.

- 하는 것: 포인트 자막 유형 판별(한 줄 가운데 / 두 줄 왼쪽 / Tip 세 줄), 모션이 끝난 상태를 렌더해 재기, 클립 모션 비율·위치 맞추기, 다시 렌더해 확인
- 하지 않는 것: 포인트 자막 고르기·배치·문구(포인트 에이전트), 기본 자막(자막 에이전트), 템플릿 파일 수정, 반응 자막의 인물 근처 배치(포인트 `fit_person.py`)

> 2026-10-14 신설 (사용자 지시: "포인트 에이전트의 "정렬" 작업을 "정렬" 에이전트로 만들어줄수있어? 작업을 에이전트로 분리하자."). 2026-10-13~14 포인트 에이전트 안에서 시작한 작업을 옮김. 다른 에이전트 파일과 섞지 않는다.

### 정해진 작업 (트리거)
| 사용자가 이렇게 말하면 | 따를 절차 |
|---|---|
| "정렬", "가이드라인", "가이드라인 맞춰" | [playbook_정렬.md](playbook_정렬.md) |

- 키워드가 없어도 **포인트 자막 크기·위치를 맞추는 요청**("자막 크기 맞춰줘", "선에 맞춰줘", "위치 통일해줘" 등)이면 먼저 "정렬 에이전트로 진행할까요?"라고 **제안**한다 (사용자: "키워드를 까먹어도 나중에 비슷한 작업으로 보이면 먼저 제안해줘").
- 포인트 에이전트가 배치를 끝내면 완료 보고 끝에 "정렬도 진행할까요?"를 덧붙인다.

## 1. 원칙
1. **원본 시퀀스는 건드리지 않는다.** 복제해서 `<시퀀스>_정렬` (있으면 `_정렬_2`…) 새 시퀀스에서 작업한다 — 복제는 `clone()` (`createNewSequence` 금지, 포인트 failures.md)
2. 바꾸는 것은 대상 클립의 **모션 비율·위치뿐**. 클립 추가·삭제·이동·문구 변경 없음
3. 측정은 **모션이 끝난 정지 상태**, **테두리·입체 그림자까지 포함한 전체 모양** 기준
4. 세트안내·반응·해설·만원은 **인물 근처에 일부러 둔 것**이라 건드리지 않는다. 불꽃처럼 그림이 섞인 자막은 **글자 기준**으로, 프리미어 그래픽(제목 없음 등)은 **작업 전에 목록을 보여 주고 고른 것만** 맞춘다 (2026-10-14 회고). 그 밖에 규칙에 없는 템플릿은 보고만 한다. 헷갈리면 작업 전후로 묻는다
5. 작업 범위(시간 구간·시퀀스)가 애매하면 묻는다. 열린 탭 목록은 스크립트로 못 읽음 → 화면 캡처로 보고, 잘리면 사용자에게 확인

## 2. 작업 전 확인
- [ ] 대상 시퀀스와 범위 (전체 / 특정 시각 이후 등)
- [ ] 시퀀스 해상도 1920×1080인지 (아니면 가이드 환산을 알림)
- [ ] `criteria.md` → `learnings.md` → `failures.md` → 최근 `log/` 순으로 읽고 반영
- [ ] 2단 클립이 새 판(줄별 크기 칸 있음)인지 예전 판인지 (`getMGTComponent()` 칸 목록)

## 3. 입력 / 출력
**입력**: Premiere 시퀀스, 가이드선 값(`criteria.md`)
**출력** (`work/포인트/정렬_<이름>/`): `clips.json`, 렌더 PNG, `plan.json`, verify 결과
Premiere: `_정렬` 새 시퀀스, 저장

## 4. 완료 보고 형식
```
새 시퀀스: [이름]
정렬한 자막: N개 (① 한 줄 가운데 a / ② 두 줄 왼쪽 b / ③ Tip 세 줄 c)
확인 결과: 바깥선 차이 최대 ?px (확인 필요 n개)
건드리지 않은 것: (템플릿 이름 × 개수)
확인 필요: (화면 밖으로 나감, 배지 없음, 줄별 조절 불가 등)
```

`scripts/point/` 의 `dump_points.jsx` · `render_solo.jsx` · `apply_guide.jsx` · **`align_guide.py`** (포인트 에이전트와 같이 씀). 순서는 playbook 4장.
