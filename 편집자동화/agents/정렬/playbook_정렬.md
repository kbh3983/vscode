## 1. 가이드선 (1920×1080 기준, 사용자 지정)
프로그램 모니터 안내선이라 스크립트·프로젝트 파일·렌더로 읽을 수 없다. 아래 값을 그대로 쓴다.

| 이름 | 방향 | 좌표 |
|---|---|---|
| **A** | 가로 (맨 아래) | y = **1028** |
| **B** | 가로 | y = **925** |
| **C** | 가로 (맨 위) | y = **840** |
| **X** | 세로 (왼쪽 정렬선) | x = **36** |
| **Y** | 세로 (가운데 정렬선) | x = **960** |

- X·Y는 선 **이름**이고, 좌표는 표의 값이다 (2026-10-13 사용자 정정).
- 해상도가 다르면 비율로 환산한다 (예: 3840×2160이면 ×2). 시퀀스가 1920×1080이 아니면 작업 전에 알린다.
- 사용자가 가이드를 바꾸면 이 표와 `criteria.md`를 함께 고친다.

## 2. 맞추는 규칙
**모든 측정은 모션이 끝난 뒤의 정지 상태 기준.** 포인트 자막은 크게 나왔다가 작아지는 모션이므로, 처음·중간 프레임으로 재면 안 된다.

| 유형 | 판별 | 세로 | 가로 | 예시 |
|---|---|---|---|---|
| **① 한 줄 가운데** | 한 줄 + 글자 가운데가 화면 가운데 근처 | 글자 위 = **B(925)**, 아래 = **A(1028)** — 사이를 꽉 채움 | 글자 가운데 = **Y(960)** | 16:43 강한말, 17:37·17:55 요약 한줄 |
| **② 두 줄 왼쪽** | 두 줄 + 왼쪽에 붙음 | 윗줄 = **C(840)~B(925)**, 아랫줄 = **B(925)~A(1028)** — 줄마다 꽉 채움 | 글자 왼쪽 끝 = **X(36)** | 18:17 요령 2단 ("한쪽 다리를 접고" / "바닥에 닿을 때까지 넘기기") |
| **③ 세 줄 왼쪽 (Tip!)** | 맨 위 "Tip!" 상자 + 두 줄 + 왼쪽 | "Tip!" 상자 **아래 끝 = C(840)**, 나머지 두 줄은 ②와 같음 | 왼쪽 끝 = **X(36)** | 18:49, 19:32 Tip 동작요령 2단 |

- "꽉 채움" = 그 줄 글자(테두리 포함, 그림자 제외)의 위 끝과 아래 끝이 두 선에 닿게. 비율은 가로세로 같이(균일 비율) 바꾼다.
- 두 줄·세 줄은 **줄마다 따로** 크기와 위치를 맞춘다. 템플릿이 줄별 크기·위치를 따로 바꾸지 못하면(모션 비율 하나뿐 등) 억지로 맞추지 말고 **작업 전에 묻는다**.
- 맞춘 뒤 글자가 화면 오른쪽 밖(x > 1884)으로 나가면 줄이지 말고 "확인 필요"로 보고한다.
- **글자 기준 (2026-10-14 회고)**: 불꽃 같은 그림이 섞인 자막은 **글자**를 B~A에, 쉼표 꼬리도 빼고 잰다. **가운데 두 줄**(작은 윗줄 + 큰 아랫줄, 예: "자극이 안 왔던 이유1 / 무게중심을 잘못 잡았을 경우")은 **아랫줄**을 B~A·가운데 Y, 윗줄은 신경 안 씀. 프리미어 그래픽 한 줄도 B~A 안으로.
- **정렬하지 않는 것**: 세트안내·반응(실망·의성어·붓글씨)·해설·만원 = 인물 근처에 일부러 둔 것 (사용자: "앞으로도 그렇게 진행하자"). 프리미어 그래픽(제목 없음/그래픽)은 반응 자막과 구분이 안 되므로 **작업 전에 목록(시점·문구)을 보여 주고 고르게** 한다.
- 이 밖에 유형에 안 맞는 것(말풍선, 배너, 새 템플릿)은 건드리지 않고 목록으로 보고한다. 헷갈리면 작업 전후로 묻는다 (2026-10-12 사용자: "헷갈리는 부분은 작업 전후로 물어보고 진행하고.").

## 4. 도구 (2026-10-14 첫 작업에서 만듦)
```
dump_points.jsx (TRACKS=**V3부터 모든 비디오 트랙** — 포인트 자막이 V3 등에 있을 수 있음, 60초 넘는 제목·테두리 클립은 빼기) → 대상만 골라 clips.json (시작 시각·템플릿 이름)
→ .venv/Scripts/python scripts/point/align_guide.py jobs clips.json <작업폴더 절대경로>
→ render_solo.jsx (jobs.json 묶음을 파일에서 읽어 2~3묶음씩, FIRST·LAST = 포인트 트랙 범위)
→ align_guide.py plan (프리미어 그래픽은 "확인 필요"로 나옴 → 사용자에게 시점·문구 목록으로 묻고, 고른 번호를 3번째 인자로 다시 plan) → apply_guide.jsx (PLAN=plan.json)
→ 확인 렌더 (jobs의 _1 시점 단독 렌더만, 이름 c→a) → align_guide.py verify → 저장
```
- 유형은 템플릿 이름으로 정함 (`align_guide.py` KIND): 강한말·요약 한줄 = ①, 요령_노랑_2단 = ②, Tip_동작요령_2단 = ③. 새 템플릿이 생기면 KIND에 추가
- 측정 = 그 트랙 단독 렌더 − 배경의 차이 영역 → **테두리·입체 그림자까지 포함한 전체 모양** (16:43 강한말이 이 기준으로 922~1024 = B~A였음)
