# 자막 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값. 원칙·절차는 `AGENT.md`.

## 입력
| 항목 | 값 | 상태 |
|---|---|---|
| 자막 텍스트 출처 | Cutback 플러그인 → SRT | 확정 (2026-10-05) |
| 입력 파일 | `work/<프로젝트명>/subtitle/cutback.srt` | 확정 |
| 텍스트 수정 | 명백한 인식 오류만 교정 (용어 사전 자동 + 문맥), 애매하면 질문. 말투·문장 다듬기 안 함 | 확정 (사용자 지시, 2026-10-05) |
| 용어 사전 자동 적용 | glossary.md의 확정·학습 중 항목 (근거에 '미적용' 표시는 제외) | 확정 |
| 학습 중 → 확정 | 사용자가 맞다고 하거나, 2번 이상 문제없이 쓰임 | 초안 |

## 싱크 (S3)
| 항목 | 값 | 상태 |
|---|---|---|
| 정렬 방식 | 연속 자막을 최대 25초 묶음으로 한 번에 정렬, 묶음 앞뒤 ±1.0초 | 초안 (2026-10-05 테스트) |
| 정렬 실패 판정 | 첫 단어가 원래 시작에서 0.8초 넘게 벗어남, 또는 정렬 길이가 예상 길이(원래 길이와 글자×0.12초 중 짧은 것)의 35% 미만 | 초안 |
| 전체 이동 적용 조건 | 자막들의 어긋남 중앙값이 0.1초 이상이고, 자막 70% 이상이 중앙값 ±0.15초 안 | 초안 |
| 시작 여유 | 첫 단어 시작 2프레임 전 | 초안 |
| 끝 여유 | 마지막 단어 끝 6프레임 후 (다음 자막 시작 전까지) | 초안 |
| 최소 표시 시간 | 0.7초 | 초안 |
| 최대 표시 시간 | 6초 (넘으면 S4에서 나눔) | 초안 |
| 자막 사이 최소 간격 | 2프레임 | 초안 |
| 시간 단위 | 시퀀스 FPS 프레임에 맞춤 | 확정 |
| 정렬 실패 | 원래 시간 유지 + 확인 필요 표시 | 확정 |

## 폭 맞추기 (S4)
| 항목 | 값 | 상태 |
|---|---|---|
| 세이프 영역 (가로) | 화면 너비의 80% | 초안 |
| 폰트 | **Pretendard** | 확정 (사용자, 2026-10-05) |
| 글자 크기 | **55px (1920×1080 기준)** → 다른 해상도는 높이 비율로 환산: 55 × 시퀀스 높이 ÷ 1080 (720p 36.7px, 4K 110px) | 확정 (사용자, 2026-10-05) |
| 글자 폭 비율 (Pretendard) | 한글 0.95em, 숫자·영문 0.6em, 공백 0.3em, 문장부호 0.35em | 초안 (실측 전 추정) |
| → 한 줄 최대 폭 | 16:9 시퀀스면 해상도와 상관없이 **한글 약 29자** (1920×1080: 1536px ÷ 52.25px) | 계산값 |
| 최대 줄 수 | **1줄** (넘으면 자막을 나눔) | 확정 (사용자) |
| 나누는 위치 | 어절 사이, 쉼이 긴 곳, 앞뒤 길이가 비슷한 곳, 쉼표 뒤 | 초안 |
| 한 단어 줄·자막 | 피함 (이웃과 합칠 수 있으면 합침) | 확정 |

## 화자 (S3b)
| 항목 | 값 | 상태 |
|---|---|---|
| 한 자막에 두 사람 | **금지.** 다른 사람이 말한 부분은 짧더라도(예: "네") 새 자막 | 확정 (사용자, 2026-10-05) |
| 화자 판단 근거 | ① 문맥(질문↔대답, 맞장구 "네·아니요", 호칭) ② 목소리 임베딩(speechbrain ECAPA) — 둘이 같으면 확정, 다르면 확인 필요 표시 | 초안 |
| 목소리 같음 판정 | 코사인 유사도 0.40 이상이면 같은 사람 (테스트: 같은 화자 평균 0.53, 다른 화자 0.25) | 초안 |
| 자막 안 목소리로 나누기 | 앞뒤 각 1.5초 이상, 앞뒤 목소리 유사도 0.10 미만일 때만 (더 느슨하면 한 문장 중간을 잘못 나눔) + 확인 필요 표시 | 초안 (2026-10-05 테스트) |
| 맞장구 떼어 내기 | 자막 앞·뒤의 "네·예·아니요·그렇죠·우와·와·아·어…"가 나머지와 0.3초 이상 떨어져 있으면 따로 자막 | 초안 |
| 목소리 비교 최소 길이 | 0.8초 (더 짧은 "네" 같은 말은 문맥 위주로 판단) | 초안 |
| 짧은 자막 예외 | 화자가 바뀐 짧은 자막은 "한 단어 자막 피함", "최소 표시 시간 합치기" 규칙보다 우선 (다른 화자와 합치지 않음) | 확정 |
| 짧은 자막 최소 표시 | 0.5초 (다음 자막 시작 전까지만) | 초안 |
