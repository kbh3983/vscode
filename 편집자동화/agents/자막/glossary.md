# 용어 사전 (자막 텍스트 교정 학습)

Cutback 자막에서 반복되는 음성 인식 오류와 바른 표기. 자막 에이전트가 **S0 텍스트 교정**에서 먼저 적용한다.

## 규칙
- **확정**: 사용자가 직접 고쳐 준 것, 또는 에이전트 교정을 사용자가 맞다고 한 것 → 다음부터 **자동 교정**
- **학습 중**: 에이전트가 문맥으로 고쳤고 사용자가 아직 확인하지 않은 것 → 자동 교정하되 리포트에 표시. 사용자가 틀렸다고 하면 지우고 `failures.md`에 기록, 2번 이상 문제없이 쓰이면 확정으로 올림
- **문맥 조건**이 있는 항목은 그 조건일 때만 바꾼다 (예: "둥근"은 운동·근육 영상일 때만 "둔근")
- `srt_tools.py`가 이 표를 읽는다: 표 형식(열 순서)을 바꾸지 않는다
