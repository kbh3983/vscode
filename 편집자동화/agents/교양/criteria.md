# 교양 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 레퍼런스 측정값이고 아직 실제 편집 결과로 검증되지 않은 값. 근거 `work/지식인사이드/분석/통합분석.md`.

> **적용 범위:** 표시 없는 줄 = 교양 공통, `[지식인사이드]` = 지식인사이드 채널(「지식인 클래스」) 전용, `[B]` = B 스타일을 쓸 때만.

## 방식
| 항목 | 값 | 상태 |
|---|---|---|
| [지식인사이드] **업체 지정 레퍼런스** | **EP.10 「"오랑캐 문자"라 비난받던 한글이…」(김진명 작가, 분석 r2)** — 수치·그래픽이 회차마다 다르면 **EP.10을 우선**. 측정: 샷 평균 6.9초, 분당 컷 16/11/7.9, 디졸브 16번(중앙 20프레임), 밝은 세트 밝기 150·채도 0.14, 오프닝 음악 30초(−44dB), −15.5 LUFS, 큰 효과음 11개(작게 23개) | 확정 (사용자 2026-10-16: "업체에서 제시한 편집 스타일 참고용 레퍼런스는 아래 영상이었어.") |
| 기본 방식 | **A 방식**: 빠른 컷, 그래픽 많음, 본론 배경음악 없음. 필요하면 B 스타일: 긴 샷, 그래픽 적음, 낮은 배경음악 | 확정 (사용자 2026-10-15: "a를 기본으로 가고, 필요시 b 스타일로 가자.") |
| [B] B를 쓸 만한 경우 | 차분한 작가 대담 등 (EP.26·29 참고) — 사용자에게 먼저 제안 | (초안) |
