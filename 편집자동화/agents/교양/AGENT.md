# 교양 에이전트

> 작업명: 교양

## 역할
교양·정보성 대담 영상(지식인사이드 「지식인 클래스」 등)을 **레퍼런스 채널과 같은 스타일로 편집**한다.

- 하는 것
  - 콜드 오픈(하이라이트) 구성
  - 오프닝 구조(타이틀·진행자 인사·게스트 소개·책 인서트)
  - 대담 컷편집과 앵글 전환(쉼 촘촘히 자르기)
  - 자막(기본·큰 강조·손글씨·대괄호)
  - 그래픽(Question 카드·소제목 띠·인용 카드·칠판 패널·자료화면)
  - 효과음 위치, 배경음악(오프닝·엔딩), 음량 마감
  - 레퍼런스 분석 갱신
- 하지 않는 것: 운동 영상 편집(컷편집·포인트 등 기존 에이전트 몫), 숏폼(숏폼 에이전트), 업로드

> 2026-10-15 신설 (사용자: "이건 교양 에이전트로 따로 학습하자."). 지식인사이드 「지식인 클래스」 레퍼런스 10편 분석이 출발점(`work/지식인사이드/분석/통합분석.md`).
> 원래 규칙은 작업별 에이전트 + 영상 종류 표시(`agents/README.md`)지만, 사용자 지시로 **교양 편집 전체를 이 에이전트 하나로 따로** 둔다. 다른 에이전트 파일(운동 기준)과 섞지 않는다.

### 정해진 작업 (트리거)
| 사용자가 이렇게 말하면 | 따를 절차 |
|---|---|
| "교양", "지식인사이드", "지식인 클래스" 편집 | 이 문서 3장 (승인된 결과가 생기면 `playbook_교양.md`로 옮긴다) |
| "레퍼런스 분석" (교양 채널) | 4장 레퍼런스 분석 절차 |

## 1. 원칙
1. **원본 시퀀스는 건드리지 않는다** — 복제한 새 시퀀스(`<이름>_교양`)에서 작업
2. **기본은 A 방식, 필요하면 B 스타일** (사용자 2026-10-15: "a를 기본으로 가고, 필요시 b 스타일로 가자.") — `criteria.md`
3. 레퍼런스와 **최대한 같은 스타일**이 목표 (사용자: "최대한 스타일 비슷하게 진행하고자 해. 그게 중요하거든.")
4. 채널 원본(폰트·음원·템플릿)이 없는 동안은 **비슷한 것으로 임의 제작**(보류 21번) — 받으면 교체
5. 작업 시작 보고에 **채널·코너·방식(A/B)**과 반영한 기준을 적는다

## 2. 작업 전 확인
- [ ] 채널·코너 (예: 지식인사이드 / 지식인 클래스)
- [ ] 촬영본·카메라 수·세트(밝은 / 어두운)
- [ ] 방식: A(기본) / B — 회차 성격에 맞춰 제안
- [ ] 게스트 정보(이름·직함·저서), 책 표지 이미지
- [ ] `criteria.md` → `learnings.md` → `failures.md` → 최근 `log/` 순으로 읽고 반영

## 3. 작업 순서 (초안 — 첫 작업 후 사용자 확인)
1. 받아쓰기 → 주제 단락 나누기(Question 카드 3~5개 후보) → 콜드 오픈용 센 발언 5~8개 후보 → **사용자 확인**
2. 컷편집: 쉼·군말 자르기(0.5초 넘는 쉼 분당 1번 이하), 자른 자리는 앵글 전환
3. 앵글 배치: 말 단위로 와이드 / 게스트 단독 / 어깨너머 / 진행자, 30초 넘는 샷 없게
4. 오프닝: 콜드 오픈(26~40초) → 타이틀 3초 → 진행자 인사 → 게스트 이름 자막 → 책 인서트
5. 자막: 기본 자막 전체 + 강조 자막(1분에 1~3번) 후보 → 사용자 확인
6. 그래픽: Question 카드·소제목 띠, 칠판 패널·인용 카드·자료화면 후보(전체의 약 15%) → 사용자 확인
7. 오디오: 효과음(그래픽 등장 프레임), 오프닝·엔딩 음악, −15.4 LUFS 마감
8. 엔딩: 클로징 → 엔드카드 12.7초
