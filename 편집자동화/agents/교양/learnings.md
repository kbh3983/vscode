```
## 제목 (날짜, 영상)
- 상황:
- 한 방법 / 사용한 값:
- 사용자 피드백 (원문):
- 다음에 적용할 점:
```

## 레퍼런스 10편 분석 → 기본 방식 A (2026-10-15, 지식인사이드 「지식인 클래스」)
- 상황: 테스트 영상 편집 전, 조회수 100만 회 넘은 영상 위주로 레퍼런스 분석 (사용자: "중요한 프로젝트라 최대한 분석이 잘 이뤄져야 해")
- 한 방법: 모든 프레임 컷 검출 + 1초·0.1초 시트 직접 확인 + 원본 해상도 자막 측정 + Demucs 분리 오디오(배경음악·효과음·LUFS) + 받아쓰기(말 속도·쉼). 5편 → 사용자가 5편 추가 → 10편 (`work/지식인사이드/분석/통합분석.md`)
- 사용자 피드백 (원문): "a를 기본으로 가고, 필요시 b 스타일로 가자." / "이건 교양 에이전트로 따로 학습하자."
- 다음에 적용할 점: 처음 5편만으로는 B 방식(EP.26·29)을 못 봤음 → 레퍼런스는 회차를 고르게(최근 회차 포함) 8~10편 보고, 편집 방식이 갈리면 표로 비교해 사용자에게 고르게 한다. 홍보 영상처럼 형식이 다른 것은 따로 뺀다
