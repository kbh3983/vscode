# 정보성 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 레퍼런스 측정값이고 아직 실제 편집 결과로 검증되지 않은 값. 근거 `work/정보성/분석/통합분석.md` (견본 `견본_궁금한뇌.jpg` 궁#, `견본_탐구생활.jpg` 탐#, `견본_세바시.jpg` 세#).

> **적용 범위:** 표시 없는 줄 = 정보성 공통(세 채널 모두), `[궁금한뇌]` = 장동선의 궁금한뇌 스타일(대담), `[탐구생활]` = 조승연의 탐구생활 스타일(1인 설명), `[세바시]` = 세바시 인생질문 스타일(1인 인터뷰), `[지식인초대석]` = 지식인사이드 「지식인초대석」 코너(진행자 + 게스트 1~2인 대담, 검은 스튜디오 — r16~r18, 통합분석 8장), `[셜록현준]` = 건축가 유현준 1인 채널(서재 설명·현장 답사, 신문·종이 콜라주 — r20~r25, 통합분석 9장), `[크랩]` = 크랩(klab) 내레이션 다큐(출연자 없음, 5~7분, 음악 계속 — r19·r26~r29, 통합분석 10장). 작업 시작 때 어느 쪽인지 먼저 정한다.
