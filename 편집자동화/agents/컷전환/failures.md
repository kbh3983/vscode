```
- 하지 말 것:
```

## [K3] V2가 옆모습을 잡는 장면을 B캠으로 넘김 — 2번 (2026-10-09, 자세교정_종편_모노_컷전환 4:57–5:08, 5:13–5:27)
- 상황: 출연자는 의자에 앉아 있고 트레이너가 뒤에서 등을 짚음. V2(C캠)가 이 장면을 옆에서 잡고 있었음
- 한 방법 / 사용한 값: "손으로 교정 = B캠" 규칙만 보고 V1으로 전환
- 같은 실수 2: 5:13–5:27 트레이너 골반·허리 시범. 트레이너가 V2 쪽으로 옆으로 서서 시범 → V2에서 허리·골반 동작이 옆모습으로 잘 보였는데 자막("골반은 여전히 말린 상태")만 보고 B캠으로 넘김
- 무엇이 문제였나 (사용자 피드백 원문): "4:57–5:08 트레이너가 등을 짚은 건 측면 화면인 V2가 더 잘보이는 각도인데 V1으로 전환되어 있어서 수정해줘." / "마찬가지로 5분 16초 - 5분 26초 구간도 V2가 동작이 더 잘 보이는 구간인데 컷이 전환되어 있어, 그 구간은 다시 V2 활성화해주고 학습해줘"
- 하지 말 것: 장면 종류만 보고 B캠으로 넘기지 않는다. **같은 시각의 V1·V2 프레임을 나란히 보고**, 등·허리·골반이 실제로 더 잘 보이는 쪽을 고른다. 출연자·트레이너 위치가 바뀌어 **V2가 옆모습(측면)을 잡는 구간은 V2 유지** — 자막·장면 종류보다 각도가 우선. 정면 V2가 B캠보다 못한 건 몸이 정면을 볼 때뿐이다

## [K1~K3] 카메라 배치를 확인하지 않고 이전 영상 전제(V2 = 정면)를 그대로 씀 + 다른 시퀀스 기준 자막 사용 (2026-10-09, 자세교정_종편_모노_컷전환 1차 → `_컷전환_1차`로 보관)
- 상황: 이 영상의 V2(C캠)는 멀리서 찍지만 **의자에 앉은 출연자를 정확히 옆모습**으로 잡음. V1(B캠)은 가깝지만 출연자를 비스듬히 앞에서 잡음. 옆구리살 영상과 캠 역할이 다름
- 한 방법 / 사용한 값: (1) "V2 = 정면이라 자세가 안 보임 → 교정 장면은 B캠" 전제를 확인 없이 적용 (2) V1·V2 프레임을 서로 다른 시각(V2 5초, V1 10초 간격)으로 따로 뽑아 나란히 비교하지 않음 (3) C3 자막 `point_captions.srt`의 주제어로 구간을 고름 — 이 SRT는 `자세교정_종편2`(787초) 기준이라 2:00 뒤로는 이 시퀀스보다 **약 9.6초 늦음** (4) 비율 30%를 채우려고 10~20초 긴 구간을 넣음
- 무엇이 문제였나 (사용자 피드백 원문): "작업해준 곳들이 전반적으로 컷전환이 잘못되어 있어, 혹시 내가 중간에 C3를 참고해서 컷전환 하라고 한게 원인일지, 아니면 또다른 원인이 있는 것일지 확인해줘, 작업 다시 하자."
- 하지 말 것: 이전 영상의 캠 역할을 그대로 가정하지 않는다. K1에서 **같은 시각 V1·V2 짝 프레임**을 보고 "누구를 어느 캠이 옆모습으로 잡는지"를 먼저 정한다. 자막 SRT는 이 시퀀스의 원본 시간과 맞는지(같은 원본 프레임이 같은 시각인지) 확인하고 쓴다. 원본에 편집자가 해 둔 전환이 있으면 그 길이·이유를 먼저 따라 한다

## [K3] B캠이 줌을 당기는 중인 구간으로 전환 (2026-10-09, 틀어진골반_종편_모노_컷전환 15:17–15:30 — 취소함)
- 상황: 서서 걷는 장면. B캠 카메라맨이 15:17–15:22에 줌을 당겨 화면이 흔들림. 배경이 흰 벽이라 가장자리 변화량 검사로는 안 잡힘
- 한 방법 / 사용한 값: 동작·각도만 보고 B캠으로 전환
- 무엇이 문제였나 (사용자 피드백 원문): "B캠이 줌을 당기고 있어서 흔들렸어, 그래서 이 구간을 넘긴 건 적절하지 않아. 이전 작업 취소하고, 다른 구간 찾아서 컷전환 해줘."
- 하지 말 것: B캠 후보는 **B캠도 줌·패닝·흔들림이 없는지** 확인하고 넘긴다. 검사: `vidstabdetect`(fileformat=1)로 초당 이동·확대량 계산 — 15:19–15:21 줌은 확대량 약 20, 안정 구간은 1~5. 클로즈업에서 손·다리가 화면을 크게 지나가면 수치가 오르므로 의심 구간은 프레임으로 확인
