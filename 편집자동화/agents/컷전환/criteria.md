# 컷전환 기준값

현재 적용 중인 기준. **사용자 승인 없이 바꾸지 않는다.** 바꿀 때는 아래 변경 이력에 남긴다.
`(초안)` = 아직 실제 결과로 검증되지 않은 값.

> **적용 범위 (2026-10-14 사용자 승인):** **표시 없는 줄 = 공통** (영상 종류와 상관없음). `[운동]` = 운동법 영상이면 채널과 상관없이, `[최박사]` = 최박사 채널의 촬영 환경·화면 구성·템플릿, `[설명]` = 설명·상담형(포인트 genre), `[강연]` = 강연 (2026-10-14 운동/최박사 나눔) (`docs/영상종류_분류안.md`).

## 작업 규칙
| 항목 | 값 | 상태 |
|---|---|---|
| **B캠은 한 사람 클로즈업으로 확대** | B캠으로 넘긴 구간은 **말하는(반응하는) 한 사람 클로즈업**으로 확대해서 씀 — 얼굴 높이 화면의 약 15%, 얼굴 가운데 y 0.23·x 0.57, 130~200% (`scripts/cutswitch/b_zoom.py` → `scripts/point/apply_guide.jsx`). 누구인지는 프레임을 보고 `who`. **넓은 옆 각도 투샷(인물이 작고 옆모습)은 B캠 후보에서 뺌** — 자세교정 최종본에서 제 B캠 20곳(44.9초)이 이 이유로 A캠으로 돌아감 | 확정 (2026-10-13 자세교정 최종본 회고 후 사용자: "8은 제외해줘. … 나머지는 말한대로 진행하자.") — 사용자 클로즈업 10곳 실측 139~192% |
| **반응·강조 자막 순간 B캠** | 반응(웃음·부정·놀람·화남)·강조 대사 순간은 B캠 한 사람 클로즈업 우선 (목교정기 0:51·5:39, 자세교정 3:17·4:33) | 확정 (2026-10-13 자세교정 최종본 회고 후 사용자: "8은 제외해줘. … 나머지는 말한대로 진행하자.") |
| [운동] **반복 동작 번갈아** | 운동 동작을 시작한 뒤 반복되는 구간은 A캠·B캠을 적절히 번갈아 씀 (지루함을 덜기 위한 목적). 옆구리살 최종본: 반복 구간 6~8초씩 번갈아, B캠 구간 중앙 7.8초·분당 2.2회 | 확정 (사용자 지정, 2026-10-12) |
| **짧은 과장 확대 컷 (예능)** | 반응·표정 등 예능적 재미를 위해 B캠(또는 A캠)을 일부러 크게 확대한 짧은 컷(1.5~5초, 115~200%)은 **에이전트가 바로 넣지 않는다** — 후보 목록만 선정 이유와 함께 사용자에게 주고, 승인한 것만 진행. 애매하면 먼저 묻기 | 확정 (사용자 지정, 2026-10-12: "이건 니가 바로 작업하지 말고 … 후보군만 나한테 주면 돼. 선정 이유와 함께.") |
| **점프컷 가리기 (중요)** | 컷편집으로 대사를 잘라 낸 지점(점프컷)은 **B캠 전환으로 최대한 티 안 나게** 가림 — 전환 경계를 점프컷 지점에 맞춰(0프레임) B캠으로 넘기거나 B캠에서 돌아옴. 옆구리살 최종본: B캠 26구간 중 9구간이 점프컷에 붙음 | 확정 (사용자 지정, 2026-10-12: "중요해. 앞으로도 유사한 작업이 반복될 거야") |
| 원본 시퀀스 | 건드리지 않음, `_컷전환` 새 시퀀스 | 확정 (사용자 지정) |

| **B캠 확대 기준 (얼굴·부위)** | ① [공통] **얼굴이 들어가는 확대**: 얼굴이 애매하게 잘리면 안 됨 — 머리 위·이마·턱이 프레임에 걸려 잘리면 크기를 줄이거나 위치를 옮겨 얼굴 전체가 들어오게. ② [운동] **운동 동작에서 특정 부위(다리·손·발 등)를 보여 주는 경우**: 그 부위를 클로즈업 (얼굴은 안 들어와도 됨). 확대 후 프레임을 보고 확인 | 확정 (사용자, 2026-10-14: "얼굴이 포함한 확대시에는 얼굴이 애매하게 잘리지 않아야 하고, 다리, 손 등 운동 동작 시 특정 부위를 보여주는 경우는 그 부분을 클로즈업하면 돼." — 틀어진골반·하체루틴 두 번 같은 피드백. **예시 이미지는 보류 19번**) |
| [운동] 트레이너 혼자 설명 | 트레이너 혼자 설명하는 장면은 **B캠 클로즈업 후보** (하체루틴 3:12·3:34) | 확정 (사용자: "5.승인") |
| [운동] 출연자 첫 시도 + 칭찬 | 출연자가 처음 해 보는 순간 + 칭찬 반응("잘하셨어요", "제대로 잡은 거죠")은 **B캠 후보** (7:48~8:06, 10:17) | 확정 (사용자: "6.승인") |
| [운동] 긴 B캠 | **14초 넘는 B캠 구간은 4~11초로 줄임** (하체루틴 7:03·10:02·16:02·17:02 → 4.3~11.6초) | 확정 (사용자: "7.승인") |
| 한 구간 길이 | 정해진 틀 없음 — 영상 종류에 따라 적절히 (예: 옆구리살 운동 10~20초, 자세교정 상담 2~9초) | 확정 (사용자 승인, 2026-10-09) |
| 자막 사용 | 쓸 때는 **이 시퀀스의 자막인지(시간이 맞는지)** 확인 후 사용 | 확정 (사용자 승인, 2026-10-09) |
| 원본 편집자 전환 | 원본에 이미 된 컷전환이 있으면 예시로 학습 (그대로 유지, 비율에 포함) | 확정 (사용자 승인, 2026-10-09) |
