# 편집자동화 프로젝트

영상 편집 자동화 프로젝트. 작업 폴더: 이 디렉터리.

## 세션 시작 시
1. docs/progress.md 를 먼저 읽고 마지막 상태와 다음 할 일을 파악한다.
2. docs/decisions.md 의 결정사항을 다시 논의하지 않는다.

## 세션 종료 시 (또는 의미 있는 작업 후)
- docs/progress.md 에 날짜별로 한 일 / 다음 할 일 / 미해결 질문을 갱신한다.
- 새로 확정된 결정은 docs/decisions.md 에 이유와 함께 추가한다.

## 규칙
- 원본은 input/ 에 두고 수정하지 않는다. 결과물은 output/ 에 만든다.
- 스크립트는 scripts/ 에 둔다.
- Premiere Pro 제어는 premiere-pro MCP 도구를 사용한다.
- 모든 프리미어 프로젝트는 빈(폴더) 3개로 구성한다: `촬영본`(원본 영상, 수정 금지) / `시퀀스`(작업 시퀀스) / `자료`(자료화면·이미지·BGM·SFX).

## 피드백 학습 규칙
- 편집 결과에 대해 사용자가 명시적으로 승인(좋다/이걸로 하자 등)했을 때만 docs/learnings.md 에 방법과 설정값을 기록한다.
- 승인 전, 또는 불만족·수정 요청이 있었던 결과는 learnings.md 에 넣지 않는다. 필요하면 docs/failures.md 에만 적는다.
- 새 편집 작업 전에 learnings.md 를 참고한다. failures.md 는 좋은 방법의 근거로 쓰지 않는다.
- 승인 여부가 애매하면 기록 전에 사용자에게 묻는다.

## 사용 안내서
- 사용자가 직접 해야 하는 절차는 `docs/how_to/`에 사용자용 안내서로 관리한다 (목록: docs/how_to/README.md).
- 사용자가 할 일이 생기거나 절차가 바뀌면 해당 안내서도 함께 고친다. 사용자가 방법을 물으면 안내서를 알려 준다.

## 에이전트
- 에이전트별 폴더는 agents/<이름>/ 에 있다. 공통 구조와 학습 규칙은 agents/README.md 를 따른다.
- 특정 에이전트의 작업(예: 컷편집)을 할 때는 해당 폴더의 AGENT.md, criteria.md, learnings.md, failures.md 를 먼저 읽는다.
- 에이전트 작업에 대한 피드백은 docs/ 가 아니라 해당 에이전트 폴더에 기록한다. docs/learnings.md 는 프로젝트 전반에 해당하는 내용만 기록한다.
