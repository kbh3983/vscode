## [모션·템플릿 재현] 원본과 똑같이 만들 때는 프레임 단위 숫자 비교 (2026-10-11)
- 명령/요청: 프리미어 모션 자막 템플릿 8개를 애프터이펙트 템플릿으로 다시 만들기 (포인트 에이전트)
- 사용한 방법·설정값: 원본과 새 것을 같은 시퀀스에 놓고 프레임마다 뽑아 위치·크기·투명도(알파 합)·흔들림(덩어리별 표준편차·앞 프레임 상관)·프레임 간 변화량·색을 숫자로 비교 → 차이마다 원인을 찾아 고침 → 비교표와 함께 보고, 사용자 눈 확인. 자세한 절차: agents/포인트/playbook_AE변환.md
- 왜 좋았는지: 사용자 "이런 프레임당 비교 후 디테일하게 작업한 부분 아주 좋아. 추후 유사한 작업 시에도 적용 가능하도록 학습해줘." — 다른 에이전트에서도 원본 동작을 재현하는 작업에 같은 방식 적용

## [샷사이즈 — 사용자 수동 편집 기준] 대화는 클로즈업, 운동 시연은 두 인물 풀샷 (2026-10-12, 옆구리살 최종 종편)
- 명령/요청: 옆구리살 최종본 회고 중 사용자 확인 — "대화장면은 일부러 더 가깝게 클로즈업, 운동 시연 장면은 두 인물 모두 잘리지 않게 풀샷을 사용한 것 맞아. 학습해줘."
- 사용한 방법·설정값 (최종본 모션 값, 4K A캠 편집자 기본 59%):
  - **대화 장면 = 클로즈업**: A캠 70%·위치 y 0.30 (0:22.89~0:35.90), 인트로 C0027 109%·y 0.69, 11:31~11:35 108%
  - **운동 시연 = 두 인물 모두 안 잘리는 풀샷**: A캠 56~57% (편집자 59%보다 약간 넓게, 0:08~0:16, 2:21~3:14)
  - 제품 인서트: A캠 242% 터틀볼 클로즈업 (11:14.14, 효과음 띠링·"터틀볼 하나면 OK" 자막과 같이)
  - B캠(1080): 106~126% 확대, 필요하면 0.5° 회전으로 수평
- 왜 좋았는지: 사용자가 직접 한 최종 편집 기준. 샷사이즈 에이전트는 삭제(2026-10-10)했으므로 자동 실행하지 않고, 다른 에이전트(컷전환·포인트 등)가 장면을 판단하거나 사용자가 샷사이즈를 물을 때 참고

## [애프터이펙트 자동 실행] 프리미어용 창 없는 AE와 구분하고, 단계마다 기록 (2026-10-12)
- 명령/요청: 사용자 "특히 애프터 이펙트 오류난 것 재발 안하도록 잘 학습해주고" (AE 스크립트가 세 번 멈추거나 실패한 뒤)
- 사용한 방법·설정값: 프리미어가 AE 템플릿을 그릴 때 `dynamiclinkmanager.exe`가 창 없는 `AfterFX.exe -m`을 띄움 → 이것과 내 AE를 구분. AE 스크립트는 **항상 `scripts/point/ae/run_ae.ps1`로**(창 있는 AE만 인정·없으면 띄우고 기다림·2개면 멈춤·끝 표시까지 대기). 템플릿 내보내기 전 프로젝트 저장. 단계마다 시작 기록. 멈추면 결과 파일 마지막 줄·CPU·명령줄·부모를 보고 원인과 함께 사용자에게 알림. 자세히: agents/포인트/playbook_AE변환.md 9장
- 왜 좋았는지: 수정 후 4번 연속 멈춤 없이 4종 모두 내보내기 성공. 어느 에이전트든 AE를 쓰면 같은 규칙

## [샷사이즈 — 사용자 수동 편집 기준] B캠은 동작 확대 + 촬영 장비 잘라 내기 (2026-10-13, 틀어진골반 최종 종편)
- 명령/요청: 틀어진골반 최종본 회고 후 사용자: "다 좋은 제안이야. 학습해줘." (참고 기록 — 샷사이즈 에이전트는 다시 만들지 않음)
- 사용한 값: A캠 67%·위치 y 0.463(위 여백 줄여 두 사람 가운데), 앉은·한 사람 장면 68~87%. **B캠 159~160% — 운동하는 다리·발로 확대하고 화면 오른쪽 조명 스탠드·박스를 잘라 냄**. 이전 자동값 150%는 트레이너를 잘라 120%로 되돌림
- 다른 에이전트(컷전환 B캠 확대 `b_zoom.py` 등)가 B캠 크기를 정할 때 참고: 사람을 자르지 말고 동작 부위 + 장비 제외

## [그래픽 템플릿 미리보기] 내보낸 뒤 정지 프레임으로 미리보기까지 한 번에 (2026-10-13)
- 명령/요청: 사용자 "프리미어 그래픽 템플릿 미리보기 화면은 첫프레임 기준이야? 다 투명으로 안 보여서 헷갈려서" → 폴더 전체 교체 → "다음에도 … 작업 이후 미리보기까지 한 번에" → "응 학습해줘."
- 사용한 방법·설정값: AE는 미리보기(thumb.png)를 0프레임으로 만듦 → 렌더의 다 나타나 멈춘 프레임으로 교체. 새 템플릿 `scripts/point/ae/finish_mogrt.py … <렌더 mp4> <프레임>`, 설치된 것 `set_thumb.py`, 폴더 점검 `thumb_scan_fix.py` + `thumb_refix_still.py`(멈춘 프레임). 자세히: agents/포인트/playbook_AE변환.md 13장
- 왜 좋았는지: 기본 그래픽 패널에서 어떤 템플릿인지 바로 알아봄. 어느 에이전트든 .mogrt를 만들면 같은 마무리
