# 작업 요청하기 — 채널·영상 종류 알려 주기

에이전트는 작업별로 하나씩이고(컷편집·컷전환·색보정·오디오·포인트·정렬 등), 같은 에이전트가 **채널과 영상 종류에 따라 다른 기준**을 고릅니다. 그래서 작업을 맡길 때 **무슨 작업 + 어떤 영상**인지만 알려 주면 됩니다.

## 1. 이렇게 말하면 돼요
| 상황 | 말하는 예 |
|---|---|
| 최박사 운동법 영상 | "최박사 운동 영상이야. 컷전환 해줘" |
| 다른 채널 운동법 영상 | "○○ 채널 운동 영상이야. 컷전환 해줘" |
| 강연 영상 | "강연 영상이야. 색보정 해줘" |
| 설명·상담형 (최박사) | "최박사 설명 영상이야. 포인트 자막 넣어줘" |

- **안 말해도 괜찮아요.** 프로젝트 이름(예: `260922_고대표님_강연`)을 보고 Claude가 짐작한 뒤, 시작 보고에서 확인을 받아요.
- 작업 이름(트리거)은 지금처럼: "컷전환", "색보정", "포인트", "정렬", "모노" 등

## 2. Claude 시작 보고에서 확인할 것
```
채널: 최박사 / 종류: 운동 → 공통 + [운동] + [최박사] 기준
```
- 틀렸으면 "아니, 강연이야"처럼 바로 고쳐 주세요.

## 3. 기준 표시의 뜻 (각 에이전트 `criteria.md`)
| 표시 | 뜻 | 예 |
|---|---|---|
| (표시 없음) | **공통** — 어떤 영상이든 | 원본은 복제해서 작업, 말소리 −4~−6dB, 자막 Pretendard |
| `[운동]` | 운동법 영상이면 **채널 상관없이** | 운동 동작 구간 무음은 자르지 않기, 시범·자세 잡기는 B캠, 요령 자막 |
| `[최박사]` | **최박사 채널만** (촬영장·화면 구성·템플릿) | 흰 배경 색보정, 정렬 가이드선, 단톡방 배너, 강한말-빨강 |
| `[설명]` | 설명·상담형 | 요약 한 줄 그래픽 |
| `[강연]` | 강연 영상 | (앞으로 쌓임) |

## 4. 피드백·학습할 때
- 평소처럼 "좋아, 학습해줘" 하면 돼요.
- Claude가 가끔 **"이건 강연 전체 기준인가요, 이 영상만인가요?"** 또는 **"최박사 채널만인가요, 운동 영상 전체인가요?"**라고 물어요. 아는 대로 답하면 그 범위로 기록돼요.
- 다른 종류 영상 피드백이 기존 기준을 덮어쓰지 않아요 (강연에서 정한 건 운동 영상에 영향 없음).
