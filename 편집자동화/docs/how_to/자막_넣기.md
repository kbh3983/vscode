# 자막 넣기

자막 텍스트는 **Cutback 플러그인**으로 만들고, Claude는 그 자막을 **화면 폭에 맞추고, 위치를 잡고, 말소리에 맞게 시간을 맞춘 뒤** Premiere에 넣습니다.

**Cutback으로 자막 만들기 → SRT로 저장 → "자막 맞춰"** 만 기억하면 됩니다.

---

## 한눈에 보기

| 단계 | 누가 | 할 일 |
|---|---|---|
| 1 | 나 | Premiere에서 Cutback으로 자막 생성 |
| 2 | 나 | 자막을 SRT로 내보내 **`cutback.srt`**로 저장 |
| 3 | 나 | Claude에게 **"○○ 시퀀스 자막 맞춰"** |
| 4 | Claude | 싱크 → 폭 맞추기 → 위치 → Premiere에 자막 트랙 넣고 저장 |
| 5 | 나 | 결과 확인, 이상한 곳 알려 주기 |

---

## 1~2. Cutback 자막을 SRT로 저장
1. Cutback으로 자막을 만듭니다.
2. 자막을 **SRT 파일**로 내보냅니다. (Cutback 또는 Premiere의 캡션 내보내기 메뉴)
3. 저장 위치와 이름:
   ```
   C:\DADA\9.AI\vscode\편집자동화\work\<프로젝트명>\subtitle\cutback.srt
   ```
   **파일 이름은 꼭 `cutback.srt`** 로 해 주세요. 폴더가 없으면 만들어 주세요.

## 3. "자막 맞춰"
> v01_sync 시퀀스 자막 맞춰

## Claude가 하는 일
- **명백한 오타는 고칩니다.** 예: 운동 영상의 "둥근" → "둔근". 문장을 다듬거나 말투를 바꾸지는 않고, 애매한 곳은 물어봅니다.
- **고쳐 주면 배웁니다.** "○○는 △△야"라고 알려 주시면 용어 사전에 넣어 다음 영상부터 자동으로 고칩니다.
- **싱크**: 각 자막의 말소리를 오디오에서 찾아, 말이 시작할 때 나타나고 끝날 때 사라지게 시간을 맞춥니다. 전체가 일정하게 밀려 있으면 한 번에 옮깁니다.
- **폭 맞추기**: 자막은 **1줄**만 씁니다 (Pretendard 55px 기준). 화면 너비보다 긴 자막은 띄어쓰기 단위로 나눕니다. 나뉜 자막의 시간은 실제 말소리에 맞춰 나눕니다.
- **화자 나누기**: 한 자막에는 **한 사람의 말만** 넣습니다. 다른 사람이 끼어든 말은 "네" 한 마디라도 따로 자막으로 나눕니다.
- **위치**: 기본은 화면 하단 가운데입니다. 다른 위치가 필요한 구간은 말해 주세요 (예: "2분 10초~2분 30초는 위쪽에").
- Premiere에 `시퀀스/<시퀀스이름>_자막` 시퀀스를 만들어 자막 트랙을 넣고 **저장**합니다.

## 4~5. 확인하고 알려 주기
- 자막이 늦게 뜨거나 일찍 사라지는 곳, 너무 길거나 잘게 쪼개진 곳을 알려 주세요.
  > 1분 30초 자막이 늦게 떠 / 자막이 너무 짧게 쪼개져
- Claude가 기준값을 고쳐 다음 영상부터 반영합니다.

## 자막을 다시 넣을 때
Premiere 스크립트로는 자막 트랙을 지울 수 없어서, **기존 자막 트랙은 직접 삭제**해 주세요. 그다음 "다시 넣어"라고 하면 됩니다.
