# 숏폼 상단 제목을 프리미어 그래픽(글자 레이어)으로 바꾸기

프리미어 그래픽의 글자 레이어는 스크립트로 문구를 넣을 수 없어요. 그래서 제목을 **자막 트랙**으로 넣어 두었고, 프리미어 기본 기능인 **"그래픽으로 업그레이드"**로 비디오 트랙의 그래픽으로 바꾸시면 돼요.

`<숏폼>_텍스트2` 시퀀스마다 들어 있는 것:
- 자막 트랙 맨 아래(새로 넣은 것) = **제목** (윗줄 흰 / 아랫줄 노랑, 0초~끝)
- 그 위 = 대사 자막 (15자)
- 빈 자막 트랙 1·2 = 지우셔도 돼요
- V6 "상단 제목"(애프터이펙트 템플릿) = **꺼 둠**. 업그레이드가 끝나면 지우세요

## 1. 첫 숏폼에서 제목 모양 맞추기 (한 번만)
1. 자막 트랙은 한 번에 하나만 보여요 → **제목 트랙**이 보이게 바꿔요 (트랙 머리의 표시 단추)
2. 제목 자막 클립을 클릭하고 필수 그래픽(속성) 패널에서:
   | 항목 | 값 |
   |---|---|
   | 폰트 | Pretendard **Black** |
   | 크기 | **100** |
   | 자간 | **−45** |
   | 정렬 | 가운데 |
   | 칠 | 흰색 (아랫줄 노랑은 문구 안에 있어요) |
   | 배경 | 끄기 |
   | 위치 | 윗줄 가운데 y≈227, 아랫줄 y≈337 (위 검정 칸 가운데, 청록 선 위). 행간으로 두 줄 간격 110px |
3. **트랙 스타일 → 스타일 만들기** → `숏폼 제목`

## 2. 그래픽으로 업그레이드 (숏폼마다)
1. (두 번째 숏폼부터) 제목 자막 클립 클릭 → 트랙 스타일 `숏폼 제목` 선택
2. 제목 자막 클립 **오른쪽 클릭 → "그래픽으로 업그레이드"** → 비디오 트랙에 그래픽 클립이 생겨요 (글자 레이어 → 텍스트 패널·속성 패널에서 문구 수정)
3. 비워진 제목 자막 트랙, 꺼 둔 V6 "상단 제목"을 지워요
4. 대사 자막 트랙이 다시 보이게 바꿔요

## 확인할 것
- 아랫줄이 긴 제목은 크기 100이면 화면 폭에 거의 꽉 차요 (특히 `틀어진골반_숏폼3` "골반 틀어짐이 교정됐습니다" — 이전 템플릿은 78%로 줄였음). 업그레이드한 그래픽에서 크기를 줄여 주세요
- 업그레이드 뒤에도 아랫줄 노랑이 남는지
