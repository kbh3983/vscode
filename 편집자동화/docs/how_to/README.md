# 사용 안내서 (How to)

편집자동화 에이전트를 쓸 때 **내가 해야 할 일**을 정리한 안내서입니다.

| 안내서 | 언제 보나 |
|---|---|
| [작업 요청하기](작업_요청하기.md) | 작업을 맡길 때 채널·영상 종류(최박사 운동 / 다른 채널 운동 / 강연)를 어떻게 알려 주는지, 기준 표시 `[운동]`·`[최박사]`·`[강연]`의 뜻 |
| [폰트가 안 보일 때](폰트_안보일때.md) | 프리미어에서 Pretendard·페이퍼로지 등 산돌구름 폰트가 갑자기 안 보일 때 (특히 프로그램이 튕긴 뒤) |
| [자막 넣기](자막_넣기.md) | Cutback으로 만든 자막을 Claude에게 넘겨 싱크·폭·위치를 맞춰 Premiere에 넣을 때 |
| [포인트 자막 넣기](포인트_자막.md) | 대사 SRT를 넘겨 포인트 자막 후보를 깔고, 골라서 학습시킬 때 |

## 모든 에이전트 공통: 피드백 말하는 법
| 이렇게 말하면 | Claude가 하는 일 |
|---|---|
| "좋아", "이걸로 가자", "학습해" | 승인 → 다음에도 같은 방식으로 함 (learnings) |
| "별로야", "틀렸어", "이건 아니야" | 거절 → 같은 실수를 하지 않음 (failures) |
| 아무 말 안 함 | 학습에 반영 안 함 (보류) |
| "앞으로도 ~하자", "기본으로 하자" | 기준(criteria)으로 확정 |
