# 숏폼 자막 트랙 스타일 지정 (한 번만)

숏폼 대사 자막은 **자막(캡션) 트랙**으로 들어가 있어요. 문구는 텍스트 패널에서 바로 고칠 수 있지만, 모양(폰트·크기·검정 띠·위치)은 스크립트로 정할 수 없어요.
그래서 첫 숏폼에서 모양을 한 번 맞춰 **트랙 스타일**로 저장하고, 나머지 숏폼에는 그 스타일만 고르면 돼요.

## 1. 첫 숏폼에서 모양 맞추기 (`목교정기_숏폼1_텍스트`)
1. 시퀀스를 열고 타임라인 맨 위 자막 트랙에서 자막 클립 하나를 클릭해요.
2. **필수 그래픽** 패널(또는 **속성** 패널)에서 다음처럼 맞춰요.
   | 항목 | 값 |
   |---|---|
   | 폰트 | Pretendard **ExtraBold** |
   | 크기 | **60** |
   | 문단 정렬 | 가운데 |
   | 칠 | 흰색 (핵심어 노랑은 문구 안에 들어 있어요) |
   | 배경 | 켜기, 검정, 불투명도 100%, 크기(여백) 약 18 |
   | 위치 | 글자 가운데가 **세로 1409** 근처(보라 선 바로 위, 영상 안 아래쪽) |
3. 필수 그래픽 패널 맨 위 **트랙 스타일 → 스타일 만들기**를 눌러 이름을 `숏폼 자막`으로 저장해요. 트랙의 모든 자막에 같이 적용돼요.

## 2. 나머지 14개 숏폼
각 `…_텍스트` 시퀀스를 열고 자막 클립 하나를 클릭한 뒤, **트랙 스타일**에서 `숏폼 자막`을 고르면 끝이에요.

## 확인할 것
- 스타일을 적용한 뒤에도 **핵심어 노랑이 남아 있는지** 봐 주세요. 노랑이 사라지면 알려 주시면 다른 방법을 찾을게요.
- 상단 제목은 자막 트랙이 아니라 **V6의 "상단 제목" 템플릿**이에요. 클립을 클릭하면 필수 그래픽 패널에서 윗줄·아랫줄 문구, 색, 크기, 위치를 고칠 수 있어요. 문구가 길면 폭 797px에 맞춰 자동으로 줄어요.
