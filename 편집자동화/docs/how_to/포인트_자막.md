# 포인트 자막 넣기

Claude가 대사에 맞는 템플릿(.mogrt) 후보를 **모두** 깔아 주면, 내가 하나씩 골라 남깁니다.
**SRT 저장 → "○○ 시퀀스 포인트" → 후보 고르기 → "포인트 검토 완료"** 만 기억하면 됩니다.

---

## 한눈에 보기
| 단계 | 누가 | 할 일 |
|---|---|---|
| 1 | 나 | 작업할 시퀀스의 대사를 SRT로 내보내 `work\포인트\`에 저장 |
| 2 | 나 | Claude에게 **"○○ 시퀀스 포인트"** |
| 3 | Claude | `_포인트` 복제 시퀀스에 후보 템플릿을 트랙별로 쌓고 마커로 후보 목록 표시 |
| 4 | 나 | 구간마다 원하는 후보 하나만 남기고 나머지 삭제 (텍스트 수정·위치 이동·전부 삭제도 OK) |
| 5 | 나 | **"포인트 검토 완료"** → Claude가 고른 결과를 학습 |

---

## 1. 대사 SRT 내보내기
**작업할 시퀀스 자체에서** 내보내야 합니다. 다른 시퀀스(가편·종편2 등)의 SRT는 시간이 어긋납니다.

### 자막(캡션) 트랙이 이미 있을 때
1. 작업할 시퀀스를 타임라인에 엽니다.
2. 타임라인에서 자막 트랙을 선택합니다.
3. **파일 > 내보내기 > 캡션** (File > Export > Captions)
4. 형식 **SubRip 자막 형식(.srt)** 선택 → 저장

### 자막이 없을 때 (음성 텍스트 변환)
1. **창 > 텍스트** 패널 → **대본** 탭 → **변환 시작** (언어: 한국어)
2. 변환이 끝나면 **캡션** 탭 → **대본에서 캡션 만들기**
3. 위 "자막 트랙이 이미 있을 때" 2~4번으로 SRT 내보내기

### 저장 위치·이름
```
C:\DADA\9.AI\vscode\편집자동화\work\포인트\<시퀀스 이름>.srt
```
예: `work\포인트\목교정기_종편_모노_색보정.srt`

## 2. "포인트"
> 목교정기_종편_모노_색보정 포인트

## 4~5. 검토
- 마커 설명에 `후보: A / B …`로 그 구간의 후보 목록이 적혀 있습니다.
- 다 고르면 **"포인트 검토 완료"** 라고 말해 주세요. 그 전에는 Claude가 `_포인트` 시퀀스를 건드리지 않습니다.
- 같은 템플릿을 비슷한 대사에서 3번 이상 고르면 다음부터 그 템플릿이 맨 아래 후보(첫 트랙)로 올라옵니다.

## 템플릿 파일명
템플릿은 `%APPDATA%\Adobe\Common\Motion Graphics Templates`에서만 가져옵니다.
파일명을 `감정_성격_용도.mogrt`처럼 `_`로 나눠 두면 Claude가 각 단어를 태그로 읽습니다. 예: `화남_부정_강조.mogrt`
