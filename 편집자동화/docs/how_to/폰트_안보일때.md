# 프리미어에서 폰트가 안 보일 때 (Pretendard·페이퍼로지 등)

Pretendard·페이퍼로지처럼 **산돌구름으로 켜는 폰트**는 산돌구름이 실행 중일 때만 쓸 수 있어요.
프리미어는 **켜질 때 한 번만** 폰트 목록을 읽기 때문에, 산돌구름보다 먼저 켜지면 그 폰트가 빠집니다.

## 해결
1. 프리미어 저장(Ctrl+S) 후 종료
2. 산돌구름이 켜져 있고 폰트 동기화가 끝났는지 확인
3. 프리미어 다시 실행 → MCP Bridge 패널에서 **Start Bridge** (경로가 바뀌었으면 Claude에게 확인)

## 예방
- 컴퓨터를 켜거나 프로그램이 튕긴 뒤에는 **산돌구름 먼저 → 프리미어 나중**
- 그래도 안 보이면 Claude에게 "폰트 안 보여"라고 하면 원인(설치 여부·실행 순서·폰트 캐시)을 확인해 줍니다
