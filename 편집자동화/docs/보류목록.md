# 보류 목록

사용자가 "나중에", "보류", "써보다가 걸리면" 등으로 미뤄 둔 것만 모은다. 당장은 중요하지 않지만 나중에 정리가 필요한 것들.
- 사용자가 "보류한 것 목록 보여줘"라고 하면 이 파일을 보여 준다
- 새로 보류하면 알맞은 우선순위 표에 더하고, 끝나거나 취소되면 "끝난 것"으로 옮긴다 (날짜·사용자 말 원문)
